资源与社区 ​

精心策划的工具和库列表，加速你的 AI 之旅。

UI 组件库 ​

更快地构建漂亮的聊天界面。

  • Shadcn UI: 复制/粘贴 React 组件的黄金标准。
  • Vercel AI SDK UI: 官方无头 Hooks。
  • NextUI: 美观、快速的 React 组件。

AI 库 (TypeScript) ​

  • LangChain.js: 编排。
  • LlamaIndex.ts: RAG 和数据。
  • Transformers.js: 浏览器内机器学习。

向量数据库 ​

  • Supabase (pgvector): Postgres + 向量。
  • Pinecone: 专用向量 DB (Serverless)。
  • Upstash Vector: 非常适合边缘部署。

学习 ​

  • DeepLearning.AI: Andrew Ng 的课程 (概念重)。
  • Vercel AI SDK 文档: 最好的实战文档。
  • Hugging Face 课程: 最适合理解模型。

社区 ​

  • Vercel Community
  • LangChain Discord
  • /r/LocalLLaMA: 用于运行本地模型。
