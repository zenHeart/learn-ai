源码调试技巧 ​

1. 查看 Gateway 日志 ​

bash
openclaw gateway --verbose

2. 诊断配置 ​

bash
openclaw doctor

3. 查看会话 ​

bash
openclaw sessions list
openclaw sessions view <session-key>

4. 测试工具 ​

bash
openclaw tools test exec -- command "ls"
