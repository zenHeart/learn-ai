dot：ChatGPT 里的常驻智能体 ​

dot 是 ChatGPT 里的常驻智能体（always-on agent：你不盯着、它也一直在干活的 AI 助手）。给它一个目标和上下文，它在两次对话之间接着推进；你关掉标签页，它照样在自己的云电脑上干活。

它接的是「长期、多步骤、要跨好几个应用盯进度」的活。本页帮你在 10 分钟内建好 dot 并派出第一个任务，再学会管住它。事实以 OpenAI 帮助中心的 Getting started with your dot 为主，截至 2026-11-24。

写给谁：会写前端代码，用过 ChatGPT，但没用过 dot，也没接触过「常驻智能体」。

非目标：不教 Codex CLI 本身，见 Codex CLI；不教 ChatGPT Work 本身，见 ChatGPT Work；不写官方页面没出现过的功能。

学完你能做什么 ​

  • 说清 dot、普通 ChatGPT 对话、Codex 各管什么，并判断一件活该交给谁。
  • 对照套餐、年龄和地区，确认自己能不能用 dot；找不到入口时知道去哪查。
  • 创建并命名一个 dot，给它一个写清「目标、资料、何时问我、什么算做完」的任务。
  • 在活动视图里找到它的任务、文件和等你批准的请求，并给反馈。
  • 写一条自定义规则，安排一个每天早上的例行检查。
  • 说清暂停、删除、断开应用各会发生什么，以及哪些事永远要你本人做。

先确认我能不能用 ​

对照套餐、年龄和地区 ​

截至 2026-11-24，帮助中心列出的范围：

套餐能不能用条件与限制
Pro能年满 18 岁；不在欧洲经济区、瑞士、英国
Plus部分账号能条件同 Pro；正在逐步放量，没轮到你时客服也开不了，重启应用也没用
Business Premium能限 ChatGPT 支持的地区，受工作区资格要求限制；逐步放量
Business Standard美国逐步开放切到你的 Business 工作区；看不到创建入口说明还没轮到；有用量限制
Enterprise / Edu / Healthcare普遍可用2026-11-18 之前的预览期，要工作区管理员为你的角色开启；自 2026-11-18 起默认可用，除非管理员退出
Free / Go未列入帮助中心的可用清单里没有这两个套餐

三条跨套餐的限制：

  • 年龄：未满 18 岁不能用。
  • 数量：Business 和 Enterprise 工作区里，每位成员可以创建一个个人 dot。发布文说，除首个 dot 外，将来才能添加更多 dot。
  • Enterprise 的驻留要求：数据或推理驻留在阿联酋的工作区不可用。受监管或 Healthcare 工作区先读 HIPAA eligible products and functionality。

官方页面之间还有几处说法对不上，比如 Plus 是否已开放、Enterprise 的驻留与 EKM 资格。本页的表照帮助中心写，差异逐条列在「深入阅读」末尾。

找到入口 ​

你在哪里怎么找
桌面网页打开 chatgpt.com/dots

核心概念 ​

先记住 dot 是什么、不是什么 ​

它是它不是
ChatGPT 里的一项功能，入口在 ChatGPT 应用内不是开源 Codex CLI 的一部分。官方文档没有给出任何终端入口
一个常驻智能体：有目标、有记忆，在两次对话之间接着干不是「一直开着的聊天窗口」。你关掉标签页，它在云电脑上照常干活
一个会分活的协调者：编码任务转给 Codex，文档类任务转给 ChatGPT Work不是写代码的 agent 本身。写代码、看 diff、提 PR 是 Codex 的活
住在云端，自带一台云电脑和浏览器不是你本机上的程序。你的电脑默认和它分开，除非你主动连接

发布文里的 specialist dots（专家型 dot）是另一回事：由公司配置身份和权限、面向组织的试点，本页只讲你个人的 dot。

把几个概念连起来看 ​

云电脑是 dot 自己的。 它有自己的文件、软件和浏览器会话，能在两次使用之间保留状态。你在自己电脑上登录了某个网站，不等于 dot 也登录了：它的云浏览器有独立的登录会话。

三种连接各管各的。 渠道负责和它说话、收它的更新；已连接的应用让它在权限内使用那个服务的信息和工具；本机电脑让它使用那台电脑的文件、应用和任务。连了其中一个，不会顺带连上另外两个。在 Slack 里找得到 dot，不代表它连上了你的邮箱。

记忆分两层。 dot 从 ChatGPT 的记忆出发，也会自己记笔记，包括从已连接的应用里得到的信息。手机端 Customize > Memory（自定义 > 记忆）显示的是共享的 ChatGPT 记忆设置；dot 自己的笔记是独立的，改那里的设置不一定改得了它已经记下的内容。

它和 ChatGPT 之间是双向的。 dot 能收到 ChatGPT 的记忆和最近的对话上下文，也能检索你过去的 ChatGPT 对话找相关内容。反过来，你和 dot 的对话也可能进入 ChatGPT 的记忆。

定时任务是你安排的，主动调研是它自发的。 你让它每天早上看日历，这是定时任务，按你给的权限执行。你不说话时它翻已连接的信息找线索，这是主动调研，只读。

内置规则打底，自定义规则加码。 dot 自带一套「什么时候自己动手、什么时候问你」的规则。自定义规则是可选的补充，用来给某类动作定更具体的边界。

Auto-review 是另一道关。 动作执行前，一个独立的安全系统拿它对照你的指令、自定义规则和安全要求，决定放行、要你批准，还是交还给你。dot 自己关不掉这道检查。

活动视图是你的仪表盘。 在桌面应用里打开 dot 的资料页就能看。每个任务有自己的对话，不会自动带入你在别处和 dot 说过的所有内容。

暂停是踩刹车，删除是清空。 暂停可以恢复，不删信息。删除不可撤销，会开始删除 dot 自己保存的记忆。两者各自的后果见下文「暂停和删除」。

它是怎么工作的 ​

读图前带着一个问题：我从 Slack 或手机发出去的一句话，经过谁，最后落到哪台电脑、哪个应用上？哪些路默认就通，哪些要我先点头？ 下面的图分三层回答：你接触 dot 的渠道、dot 本身、它能动用的东西。

图的依据： 三层的对象来自帮助中心 Getting started with your dot：dot 有自己的电脑；创建后可以在手机应用、桌面应用里和它对话，手机网页不支持；本机电脑访问是可选的，默认关闭；Codex 云环境要先在 Codex 里建好；应用通过 Plugins 连接。Slack 与 Teams 两个渠道、以及「上下文跨渠道延续」来自发布文 Introducing dots。图中保留了三层的对象、消息与进度的往返方向，以及默认可用和需要你授权的区别；省略了每一项的设置步骤、dot 的内部实现，以及它把任务委派给 ChatGPT Work 或 Codex 的细节。实线是默认就通的路，虚线是需要你显式授权或先建好的路。

图里最该盯住的是两点。

第一，dot 站在中间。 渠道只是入口。换渠道不会得到一个新的 dot，也不会重置它的记忆。消息留在各自的渠道里，dot 可以跨渠道使用相关上下文。

第二，第三层不是默认全开的。 dot 一创建就有云电脑和浏览器。应用和插件要你自己连。本机电脑默认关闭，点了 Allow access（允许访问）才通。Codex 云环境要先在 Codex 里建好。渠道和第三层之间没有直接连线：连了 Slack，不会自动连上你的邮箱或电脑。

企业工作区多一层：管理员可以分别关掉 dot 的云浏览器、代码联网和电脑操作。关掉之后，dot 仍能起草内容、整理信息、使用工作区允许的已连接应用。

dot 干活时会把一部分工作分出去：用后台 agent 并行处理，开单独的云线程，在已连接的电脑上创建 Work 或 Codex 任务。云线程会作为单独的对话出现在桌面、网页和手机应用里，你可以打开继续指挥。它也能接着做已有的本机 Codex 任务。

发布文写明 dot 由 GPT‑6 Astra 驱动；2026-11-03 的更新注记说，驱动 dots 的模型家族新增了 GPT‑6.1 Terra。

Cindy 是开源的智能体应用，走的是另一条路。它装在你的电脑和手机上，官方 README 的说法是「你的电脑成为你的服务器」。

对比项dotCindy

10 分钟创建 dot 并派出第一个任务 ​

这条最短路径不连接你的电脑，任务模板也不让它对外发消息。六步是：确认入口、创建并命名、接一个应用、发任务、看结果、给反馈。

1. 确认入口 ​

打开 chatgpt.com/dots，或手机应用的 Dot 标签页。看得到创建入口就继续。看不到就回到上一节查套餐和工作区。

2. 创建并命名 ​

  1. 在手机应用、桌面应用或桌面浏览器里打开 dots，跟着引导走。
  2. 给它起名、选外形。可以先保留默认，以后再改。
  3. 连接插件这一步可以先跳过，下一步再接。

它会自我介绍，并根据手头的上下文建议自己能帮什么。默认 handle 是 @你的用户名-dot，起名后变成 @你的用户名-你起的名字。以后改名或头像：点它的名字或头像打开资料页，再点铅笔图标。

3. 接一个应用 ​

手机端打开 dot 的资料页，进 Customize > Plugins（自定义 > 插件）。选一个受支持的应用，连接前先看它的权限，再连。桌面端可以在 ChatGPT 的 Plugins 标签页里连接和管理。

这个界面用的是共享的 ChatGPT 设置。你在 ChatGPT、ChatGPT Work、Codex 里连过的应用，dot 可以在你已授权的范围内使用。发布文（2026-09-29）说插件生态能连 4,000 多个应用；帮助中心提醒，对你可用的应用可能不同。

4. 发出第一个任务 ​

任务里写清四件事：目标、可用资料、什么时候问你、什么算做完。下面这段可以照抄，把尖括号里的内容换掉：

text
我要你帮我盯一件事：<项目名> 的依赖更新。

目标：告诉我 <某个依赖> 的最新版本改了什么，会不会影响我们。
可用资料：<代码仓库链接> 里的 package.json 和更新日志，当前版本我用 + 号附上。
什么时候问我：要改代码、开 PR，或在群里发消息之前，先问我。
什么算做完：一段话，写清最新版本号、和我们相关的三条变更、影响大不大及理由。
先做一版给我看，我确认之后，再谈要不要持续盯着。

要附文件或照片，在对话里点 +。

5. 在活动视图里看结果 ​

在桌面应用里点 dot 的名字或头像打开资料页，在 In progress（进行中）、Scheduled（已定时）、Completed（已完成）下看活动。打开任务可以看进度、文件和结果。

想亲眼看它在干什么：从资料页打开它的电脑。要动手操作，点 Take over（接管）；用完点 Return control（归还控制权），它才能接着干。

6. 给反馈 ​

直接在对话里回复，补充信息或改方向。结果不对时，打开出问题的那个任务，在里面说清楚你要的结果，附上相关文件或链接。

第一个任务怎么选 ​

从你经常要查看或更新的一件事开始。先交一版给你审，再扩大职责。官方举的三类例子：准备演示文稿、把访谈转成内容、改进一个应用。

日常用法 ​

写第一条自定义规则 ​

对「分享、购买、访问」这三类动作，你可以给某一类操作定一条规则。

  • 手机端（帮助中心）：打开 Customize > Custom rules（自定义 > 自定义规则），查看默认规则或添加一条。
  • 桌面和网页（官方文档）：打开 Settings > Personalization，在 Permissions 下选 Custom rules，点 Add。

描述这条规则覆盖的动作，从下表选一种处理方式。手机端点对勾保存，桌面端点 Add rule。

处理方式含义前端工程师的例子
Take action without asking（不问直接做）直接做，不请求批准把整理好的当日日程摘要发进和你的 ChatGPT 对话
Take action if pre-approved（已获预先批准时执行）你在提示里明确要求过才做；否则动手前立刻问往团队 Slack 频道发周报草稿：只有你在任务里点名让它发，它才发
Ask before taking action（执行前询问）做之前先要你批准开 PR、合并分支之前先问
Hand off to you（交由你处理）请你自己来做这个动作删除共享的项目文件

「pre-approved」指你在提示里明确要求过这个动作。官方文档把第二种写作 Take action when you say so，意思相同。

四条边界：

  • 不必每次批准都写规则。先在对话里把要求说清楚，需要长期生效的边界才写成规则。
  • 规则不授予应用或电脑访问权限，也不覆盖内置安全机制。改密码这类步骤必须你本人完成。
  • dot 会犯错，照着你的规则执行时也会。采信结果前先审一遍。
  • Enterprise 工作区的自定义规则默认关闭，要管理员打开。工作区禁用时，已保存的规则不生效，你也改不了。

安排每天早上的例行检查 ​

直接告诉它。固定时间重复的活要写清四点：查什么或更新什么、什么时候跑（含时区和结束日期）、哪些变化值得通知你、结果送到哪里。例：

text
每个工作日早上 9 点（北京时间），未来四周，查看我连接的日历和团队的排期频道。
有截止日期变了，就更新项目清单。
只有在某个截止日期有风险，或者需要我做决定时，才在 ChatGPT 里告诉我。
设好后，把你保存的计划复述给我确认。
  • 运行结果和主动更新会出现在对话里。
  • 管理入口有两个：在 dot 资料页的 Recent activity（近期活动）里点那个任务，或打开 ChatGPT 的 Scheduled。这里能看到进行中、已暂停、已完成的任务。
  • 打开任务可以改重复周期、时间或完成通知。
  • 让它复述保存了什么。你也可以直接让它列出、修改或取消自己的定时任务。

两个提醒：

  • 它还能读写你已有的 ChatGPT Work 定时任务。让它「调整一下排期」时，说清是哪一个。
  • 某次运行即使标成了「已完成」，也要看一眼结果。

在 Slack 里找它 ​

  1. 在桌面端 ChatGPT 里打开 dot 的资料页，点 Add（添加）连接 Slack。
  2. 给你的 dot 发私信。或者把它加进某个频道，在话题里 @ 它。

连上以后：

  • 默认它只回应你。你可以让它也回应别人。
  • 告诉它哪类消息送到哪。比如日常进度留在 ChatGPT，要你拍板的事发到 Slack。
  • 想让它盯某个频道，要明说看哪些频道、注意什么、什么时候通知你，并让它确认。只把它拉进频道，不等于建立了监控。

两条边界：只有 dot 的主人能指挥它，别人的私信或 @ 不会让它开工。你可以让它回应别人，但那仍然是你下的指令，对方并没有获得指挥权。它在频道里发的消息，频道里的人都看得到。官方安全指南建议只在组织内部成员都在的频道里使用 dot。

企业工作区还有两道关：管理员打开 dots 和「添加到 Slack 与 Microsoft Teams」的权限；Slack 工作区需要审批的，由 Slack 的管理员批准。之后每位成员自己完成连接。

从手机看进度并接管 ​

  1. 在 ChatGPT 手机应用里打开和 dot 的对话。要看它的电脑，从资料页打开。
  2. 手机端打开时，控制权直接在你手里。桌面端只是打开拿不到控制权，要点 Take over 才能用它的鼠标和键盘。
  3. 用完点 Return control，它才能继续。

通话：打开 dot 的对话，点电话按钮；桌面应用里也可以在资料页点 Call。通话时可以打字，挂断后交给它的活可以继续。发布时 dot 不能主动给你打电话。

短信是另一条渠道，但开放范围两个官方页写得不一样：帮助中心写的是美国、加拿大、墨西哥的部分 Pro 用户，官方文档写的是只向美国的 Pro 用户开放。两边都要求 iMessage 或 RCS。帮助中心还写明，Business 和 Enterprise 工作区不支持短信。设置入口是资料页的 Texting；看不到这一项，说明还没轮到你的账号。

手机网页不支持 dot，要用手机应用。想换一个渠道接着聊，直接换：还是同一个 dot。

连接本机电脑，让它在你的项目里开 Codex 任务 ​

先看风险，再决定连不连。

  • 授权是长期的，而且跨渠道生效。 确认 Allow access 后，无论你从哪个渠道和 dot 说话，它都能访问那台电脑上的文件、在上面干活。连接在任务之间一直保留。
  • 活在本机跑，协调在云端。 对话、工具结果和任务上下文不会只留在那台电脑上。
  • 它能在上面开任务、用工具。 连接后它可以创建 Work 或 Codex 任务、使用本地技能，并在云浏览器被挡住时改用你的本地浏览器。
  • 和 Codex 的连接是两回事。 把电脑连到 Codex 或开启 Work Sync，都不会让 dot 获得本机访问权限。反过来也一样。
  • 离线不等于断开。 Offline（离线）只表示电脑暂不可用，授权还在。要收回必须点 Revoke access（撤销访问权限）。
  • 用摄像头、麦克风或屏幕还要系统权限。 前提是电脑已连接，并且你在设备设置里允许了 ChatGPT 应用使用它们。

决定要连，就在那台电脑上操作：

  1. 打开 ChatGPT 桌面应用，进入 dot 的资料页。
  2. 在 Computers（电脑）下找到 Your computer（你的电脑），点 Allow access。
  3. 阅读确认提示，再点一次 Allow access。

那台电脑要保持在线、开着 ChatGPT 应用，dot 才能用它。本机上的工作会作为独立任务出现在侧边栏里。官方企业管理文档另要求桌面应用为 26.929 或更高版本。

连好后可以这样交代：

text
在我的电脑上，为 <项目目录> 开一个 Codex 任务：<要改什么>。
做完给我看 diff 和测试输出。不要合并，也不要推送。

查看或收回：资料页的 Computers 下能看到已连接的电脑，点 Revoke access 收回。

让它用 Codex 云环境 ​

你的电脑不开机，dot 也能跑编码任务，前提是先在 Codex 里把环境建好。

  1. 在 Codex 里创建并发布一个环境。官方文档给的入口有两个：新任务里选 Work in > Cloud，打开 Select environment，选 Create environment；或从 Settings > Codex Cloud > Environments 进入。建完要点 Publish。背景见 Codex Cloud。
  2. 回到和 dot 的对话，让它在这个环境里创建任务。说清用哪个环境、改什么。
  3. 在活动视图里打开任务看结果。

环境里要有这个仓库和它的配置。官方的要求是：先在 Codex 里建好，再去找 dot。

两条限制：云环境不支持电脑操作和浏览器操作；你本机的个人技能不会同步到云环境。

哪些事永远要你本人做 ​

  • 改密码、在金融账户之间转账。 dot 可以帮着做周边的事，但这些步骤必须交还给你。
  • 每次都要你确认的动作。 永久删除数据、安装或运行来源不明的软件、授予新的安全敏感权限。
  • 验证码和安全验证。 它可能需要你提供验证码，或者接管过去自己完成。

还要知道的边界 ​

  • 只有你能指挥你的 dot。 别人的私信或 @ 不会让它开工。它在频道里发的消息，频道里的人都看得到。
  • 批准有范围。 批准一条消息，不等于允许它以后一直替你联系别人。
  • 花钱要你点头。 它可以用你在商家网站保存的卡下单，但需要你批准。用 Wallet 结账时，每笔付款都要你用生物识别确认。
  • 审查不是万无一失。 dot 会犯错。官方自己写明，Auto-review 对浏览器、桌面和委派动作的覆盖仍在评估中。
  • 网页、邮件、文档里可能藏着恶意指令。 这叫 prompt injection。dot 被训练成区分你的指令和它读到的内容，但这些防护只降低风险，不能消除风险。
  • 它和 ChatGPT 共享记忆，且删不掉单条。 dot 能收到 ChatGPT 的记忆和最近的对话上下文，也能检索你过去的 ChatGPT 对话。你目前不能查看、删除或修改单条 dot 记忆。关掉 ChatGPT 的 Memory 只停止共享，不删除它已经收到的信息。
  • 撤回不保证成功。 已经完成的动作能不能撤销，取决于动作和应用。删除 dot 也不会撤销它在已连接应用里做过的改动，或收回已经送达的消息。
  • 数据用途由设置决定。 Business、Enterprise、Edu 工作区默认不拿你的内容训练模型。个人套餐看「Improve the model for everyone」这个设置。OpenAI 不会直接拿主动调研和 dot 给自己的笔记训练模型。
  • 本机访问有收尾时间。 管理员关掉本机访问后，已经授权的本地任务可能还在跑完。
  • 建议开多因素认证（MFA）。 入口在 Settings > Security and login。

受监管或 Healthcare 工作区另有一层：隐私与安全 FAQ 说 dots 在满足条件时属于 HIPAA eligible，但同一家帮助中心的 HIPAA 文章把「Use Codex in the cloud」列在不覆盖的清单里。让 dot 转交 Codex 云环境任务之前，先和管理员确认。

  1. 在你希望 dot 使用的那台电脑上，打开 ChatGPT 桌面应用里的 dot 资料页。
  2. 在 Computers 下找到 Your computer，点 Allow access。
  3. 阅读确认提示，再点一次 Allow access。

保持那台电脑在线、开着 ChatGPT 应用。Offline 只表示电脑不可用，不表示连接被撤销。Allow access 点不了，确认你是在那台电脑上用桌面应用。

dot 用不了某个应用或网站 ​

  1. 已连接的应用：确认装了受支持的插件，而且连的是正确的账号。
  2. 看它被允许的动作。能读信息，不一定能改信息或发消息。
  3. 连接过期了，打开重连请求重新连接。
  4. 需要登录的网站：完成 dot 发来的登录请求，包括网站要求的验证。或者接管，自己登录，完成后归还控制权。
  5. 网站屏蔽云浏览器：让 dot 改试你已连接的电脑。这可能另开一个本地任务，不会带上云浏览器的会话，也不保证网站就能用。

我批准了，操作还是被拦 ​

  1. 打开出问题的任务，看有没有单独的登录、连接或批准请求。
  2. 看相关的自定义规则。如果它要求你明确下令，就直接要求 dot 执行这个动作。
  3. 记住两条：自定义规则不授予应用或电脑访问权限，也不覆盖内置安全机制。有些步骤（比如改密码）必须你本人完成。

找不到 dot 的工作成果或文件 ​

  1. 在桌面应用里点 dot 的名字或头像，打开资料页，再打开相关任务。
  2. 本地任务在已连接电脑的侧边栏里。循环执行的工作在 Scheduled 下。
  3. 回到任务最初所在的电脑或云环境找。换了 dot 使用的电脑，已有任务不会搬过去。
  4. 要看它的云电脑，去资料页的 Computers 下。要亲自操作就点 Take over，完事点 Return control。

dot 停了，或漏了指令 ​

  1. 打开出问题的任务，处理所有等你决定、批准、登录或连接的请求。
  2. 是你暂停的，就恢复它。是管理员暂停或收回了权限，就去找管理员。
  3. 循环执行的工作：打开 Scheduled，核对保存的指令和时间。即使标成完成，也要看结果。
  4. 纠正要发在出问题的那个任务里，写明你要的结果，附上文件或链接。
  5. 要报 bug、提反馈，在和 dot 的主对话里说。它也可能主动建议你提交反馈。

找不到 dot ​

确认用的是正确的账号和工作区，再打开 chatgpt.com/dots。按套餐对号：

  • Plus：支持地区内向部分账号逐步开放。
  • Pro：欧洲经济区、瑞士、英国以外，年满 18 岁的用户可用。
  • Business Premium：ChatGPT 支持的地区可用，受工作区资格要求限制。
  • Business Standard：切到你的 Business 工作区。还看不到创建入口，说明可能还在向你放量。手机上用最新版应用。
  • Enterprise，含 Edu 和 Healthcare：问工作区管理员，你的角色有没有开 dots。

和 dot 通话有问题 ​

打开和 dot 的对话，点电话按钮。通话不好用但聊天可用，就在对话里打字继续。

改了 Memory 设置或删除 dot，会变什么 ​

  • 手机端 Customize > Memory 显示的是共享的 ChatGPT 记忆设置。dot 自己保存的记忆是独立的，改那里不一定会改它已经记下的笔记。
  • 删除 dot 会结束对它的访问，并开始删除它自己保存的记忆。先存好要用的结果，看清删除提示再确认。
