Cursor ​

核心概念 ​

Symbol (符号) ​

使用符号来添加上下文，并让 Cursor 执行特定操作。

符号功能演示
@code代码片段
@file将文件包含到上下文中
@Folders将文件夹包含到长上下文中当你希望上下文只指向特定子目录时很有用
@doc帮助 Cursor 理解额外知识 (文档)
@git一些 Git 工具
@codebase整个代码库上下文
@web运行网络搜索
@chat聊天记录作为上下文
@link总结链接内容

配置 ​

  • .cursorignore: 让 Cursor 忽略某些文件，类似于 .gitignore

快捷键 ​

功能块快捷键功能备注
配置⌘⇧J打开 Cursor 设置
交互⌘L在 Cursor 中触发 AI 聊天
⌘⇧K触发内联聊天 (Inline Chat)
⌘⌥L打开聊天后，使用此快捷键选择历史聊天
