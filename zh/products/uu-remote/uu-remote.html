网易UU远程上手教程 ​

网易UU远程（网易出品的远程控制软件）解决一件事：人不在电脑旁边，也能看到它的屏幕、操作它、取它的文件。本页的目标是让你在 10 分钟内，用「设备 ID + 验证码」连上第一台电脑并操作一次。

本页的界面文字与数字来自 2026-11-24 打开的网易官方页面。会变的内容（价格、版本、权益）都标了日期。

学完你能做什么 ​

  • 说清主控端、被控端、设备 ID、验证码各是什么，分得清「临时协助」和「无人值守」。
  • 在 Windows、macOS、手机、平板上装好网易UU远程，并把一台 Mac 设成可被控。
  • 用「设备 ID + 验证码」连上一台电脑，打开它的一个窗口，再安全断开。
  • 把自己的电脑配成随时可连：固定验证码、开机自启、远程开机。
  • 传文件、切多屏、开防窥，知道免费版和 VIP 的边界，也知道哪些信息不能给。

先决条件与环境要求 ​

  • 写给谁：会写前端代码、用过命令行，但没接触过远程控制软件的人。
  • 先决条件：
    • 两台联网设备。一台当被控端（Windows 或 macOS 电脑），一台当主控端（Windows、macOS 电脑，或 Android、iOS 手机平板）。
    • 一个网易UU远程账号。主控端要登录；被控端接受「远程协助」时不用登录。
    • 被控端电脑开机、已联网，并且网易UU远程客户端正在运行。
  • 非目标：
    • 不讲内部实现。官方没有公开建连流程、编解码器、协议和服务器架构，本页一律不写。
    • 不讲 UU加速器、MuMu模拟器、网易千千壁纸，也不讲「云设备」（游戏云电脑、AI 云电脑）。它们是官网导航里另外的产品。
    • 不对比其他远控软件的功能和价格。本页没有打开它们的官方页。
    • 界面文字以你所用版本为准。本页引用的按钮名来自官方帮助页。

核心概念 ​

远程控制的词不多，但每个词都分「哪一端」。先过术语表，再看展开。

远程控制是什么 ​

官方在《网易UU远程软件许可及服务协议》里的定义是：在异地连通被控制的计算机，把它的桌面环境显示到自己的计算机上，再通过本地计算机对远方的计算机做配置、安装程序、运行程序等操作。

同一份协议写明了两件事，新人必须记住：

  • 被控制方可以随时停止授权，方式是断开连接、取消分享等。
  • 软件暂无法限制控制方的操作权限。一旦成为被控制方，控制方从技术上可以做系统启动后的所有操作，包括查阅和传输所有文件、安装和卸载应用、重启和关机。

所以，设备 ID 加验证码等于这台电脑的整把钥匙，不只是「看一眼屏幕」的门票。出处见软件许可及服务协议。

主控端与被控端 ​

主控端（你手里拿着、用来操作的设备）负责发起连接、显示画面、发送键鼠操作。被控端（被远程操作的那台电脑）负责提供画面、执行操作。两台设备都要安装网易UU远程。分不清两端，设置就会配错：远程开机的网卡和 BIOS 设置全在被控端，[控制中心] 里的画质设置在主控端。

哪些设备能当哪一端（截至 2026-11-24 官方下载页与帮助页）：

主控端能操作的被控端
Windows、macOS 电脑Windows、macOS 电脑
Android、iOS 手机和平板Windows、macOS 电脑
Android TV仅 Windows 电脑

三点补充：

  • 手机和平板不能当被控端。安卓设备只能把屏幕「共享」给别人看，对方只能观看、听声音、批注，不能操控。
  • Linux PC 端和 HarmonyOS 移动端处于内测。官方内测页写明：Linux 既能当主控端也能当被控端；鸿蒙版只能当主控端。见 Linux 内测常见问题 和 HarmonyOS 内测常见问题。
  • 远程开机，正式版帮助页只讲了 Windows 电脑。Linux 内测页写明 Linux 被控端也支持，仍属内测。

两条连接路线：远程协助与同账号远控 ​

对比项远程协助同账号远控
怎么确认身份主控端输入设备 ID 和验证码两端登录同一个账号
被控端要不要登录不要要
主控端入口[远程协助]-[开始协助]主页面点[进入桌面]
适合帮父母、同事、客户修电脑；跨账号连接连自己的设备
用不到的能力不能创建虚拟屏、超级屏；没有独立的[文件传输]入口；没有「终端」需要账号，设备要出现在列表里

为什么要有两条路线：帮别人修电脑时，你不该把自己的账号登到对方机器上，对方也不必为了被帮而注册账号。连自己的设备时，每次报验证码又太麻烦。

设备 ID 与验证码 ​

设备 ID（每台设备的一串编号）在客户端的[远程协助]-[开始协助]页，[本设备]区域里写着[本设备ID]和[设备验证码]。点[复制并分享]可以把两项一起发出去。复制的内容里还有一条邀请链接，默认 30 分钟有效。

验证码（连接时要出示的口令）分两种：

  • 临时验证码：会自动更换。刷新时间可选「每次远控结束」「每小时」「每 12 小时」「每 24 小时」，在[自动刷新]里设置。选[关闭]就不再更换，需要时点[立即刷新]手动换。
  • 自定义验证码：你自己设的固定码，8 到 16 个字符，必须含数字和大写字母。在[设置]-[安全]的[自定义验证码]里，可以选「仅使用自定义验证码」或「同时使用两种验证码」。

被控端还能决定「用哪种方式允许别人连进来」，共三种，默认是第一种：

验证方式主控端做什么被控端做什么
「验证码连接」（默认）输入设备 ID 和验证码无需操作
「双重验证」输入设备 ID 和验证码校验通过后，还要在 60 秒内点[允许]
「免密连接」只输入设备 ID在 60 秒内点[允许]

「双重验证」和「免密连接」只有 Windows 被控端提供，超时视为拒绝。macOS 被控端只支持「验证码连接」。没有验证码会怎样？知道设备 ID 的人就能连。所以官方提醒：开启[允许他人远程协助]后，任何拿到设备 ID 和验证码的人都能尝试连接。出处见如何远程协助他人电脑。

无人值守与安全密码 ​

无人值守（被控端没人守着也能连）在官方功能页里的做法是「自定义长效验证码」。落到操作上是三件事：

  1. 给被控端设一个固定的自定义验证码，或者让两端登录同一个账号。
  2. 在被控端[设置]里开启[开机自动启动]，重启后客户端还在。
  3. 需要时再配远程开机，让关机的电脑也能被唤醒。

安全密码（给客户端上锁的密码）容易和连接密码混淆。它属于「安全锁定」功能：锁定后，别人不能在被控端本地修改客户端设置，也不能正常退出客户端，但远程连接照常可用。安全密码为 8 到 16 位，入口在客户端右上角[更多]-[安全锁定]。没有它会怎样：能碰这台电脑的人可以关掉[允许他人远程协助]，或改掉你的验证码。给父母的电脑配无人值守时，建议一起开。

远程开机 ​

远程开机（用网络把已关机的电脑唤醒）基于 WOL（Wake-on-LAN，网络唤醒）：网卡收到一个特定的「唤醒数据包」（官方称 Magic Packet），就把电脑唤起。

被控端要同时满足四个条件，缺一个都唤不醒：

条件说明
网卡支持并开启网卡支持网络唤醒，并在网卡驱动里打开 WOL 选项
主板支持并开启主板支持网络唤醒，并在 BIOS 里打开 WOL 选项；官方注明笔记本基本不支持
局域网内有辅助设备辅助设备（和被控端同一局域网、一直在线的设备）负责发唤醒包，可以是登录同一账号的 Windows、macOS 或 Android 设备，部分型号路由器也可以
客户端已放行被控端开启[开机自动启动]和[允许通过远程开机启动]，且没有被第三方软件拦截

没有远程开机会怎样：电脑一旦关机，任何远程控制都连不上。操作步骤见下文「远程开机」。

直连与中转 ​

  • 直连：两台设备之间直接传数据。官网首页写的是「高速直连」「高速专网直连」。
  • 中转：数据经官方的中转线路转发。会员权益表里有「手动切换远控中转线路」「文件传输高速中转通道」两项。

官方没有公开什么情况下走直连、什么情况下走中转，以及两者的判定规则。你不需要懂这部分也能用：连接由客户端自己完成。

画面串流 ​

画面串流（被控端把屏幕画面和声音实时传到主控端显示）是你看到远程桌面的方式。它有三个可以调的旋钮：分辨率（官方给的上限是 4K）、帧率（上限 144 帧）、码率（上限 500 Mbps）。另外两个开关是真彩模式（4:4:4 色彩采样，保留完整色度，文字边缘更清楚）和 HDR。

官网的 llms.txt 专门提醒：不要把 4K、HDR、144 帧或 4:4:4 真彩当成所有设备和网络下的固定效果。它们还受显卡、系统版本和会员档位限制，见「费用」一节。

它是怎么工作的 ​

带着这个问题看下一张图：我在主控端输入设备 ID 和验证码之后，画面和操作是怎样在两台设备之间来回的？

图的依据： 三个对象与五个步骤来自官方远程协助功能页和帮助中心的远程协助他人电脑；「画面、操作实时同步」与「端到端加密」出自官网首页（截至 2026-11-24）。图中保留了三个对象、两条方向相反的数据流和每次操作的循环；省略了建连的内部流程、数据走直连还是中转，以及编解码器、传输协议和加密算法，这些官方都没有公开。网易的服务画在上方单独一个框，不夹在两台设备之间，就是为了不暗示数据经过它。

图里主控端在左、被控端在右，两条方向相反的数据流都是横向的。下行（被控端到主控端，图里从右往左，第 3 步）是画面和声音，量很大，所以分辨率、帧率、码率决定它占多少带宽。上行（主控端到被控端，图里从左往右，第 4 步）是键鼠事件，量很小。你在主控端每动一下鼠标，就走一遍「上行、执行、下行」，也就是图里的第 4、5、3 步。

建连那一步只画了一个框。官方公开的说法只有三点：输入设备 ID 与验证码即可连接、画面与操作实时同步、端到端加密。中间怎么校验、数据走直连还是中转，官方没有公开。

安装 ​

各平台怎么装 ​

平台怎么装系统要求官网版本（截至 2026-11-24）
Windows下载页「Windows 版客户端」点「立即下载」Win 11、Win 10、Win 8 等V 4.48.2，更新于 2026.11.20
macOS下载页「macOS 版客户端」点「立即下载」macOS 11.0 及以上V 4.48.2，更新于 2026.11.20
iPhone / iPad下载页点「前往 App Store」iOS 14.0 及以上下载页写 V 4.48.0
Android 手机 / 平板下载页点「点击下载 APK」Android 8.0 及以上V 4.48.2，更新于 2026.11.20
Android TV电视应用中心搜「网易UU远程」，或下载安装包后用 U 盘装Android 8.0 及以上V 3.5.0，更新于 2025.03.03

两点注意：官方不支持 32 位 Windows，安装报错 216 就是这个原因。App Store 上的版本可能比下载页标注的新，以商店页为准。

两端都安装并登录 ​

  1. 在被控端电脑上，从下载页下载对应安装包并安装。安装向导里的选项以界面为准。
  2. 打开客户端，注册并登录。被控端如果只接受远程协助，不登录也可以。
  3. 在被控端的[设置]里开启[开机自动启动]。重启后客户端会自动运行，你才连得上。
  4. 在主控端设备上安装，并登录你的账号。发起远程协助时，主控端必须是登录状态。

让 Mac 可以被控 ​

Mac 被控端要多做三步，其中前两步缺一步都会连不上或黑屏：

  1. 点客户端右上角[设置]，切到[安全]选项卡，勾选[允许本设备被控]。
  2. 按弹窗点[去开启]，在 macOS 里给网易UU远程打开[录屏与系统录音]和[辅助功能]两项权限。前者决定能不能看到屏幕，后者决定能不能用键鼠操作。
  3. 关闭并重新启动客户端。官方强调，不重启权限不会完全生效。

误关了弹窗时，手动路径是[系统设置]-[隐私与安全性]。如果要用无线副屏、把 Mac 当主屏，还要在同一页开启[允许同账号控制本设备]。出处见如何通过网易UU远程控制 Mac。

10 分钟跑通第一件事：用设备 ID 和验证码连一次 ​

目标：在主控端看到被控端桌面，打开并关闭一个窗口，然后断开。全程用默认的临时验证码，最安全。

被控端：打开开关，复制连接信息 ​

  1. 打开网易UU远程，进入[设置]-[安全]，开启[允许他人远程协助]。你会看到[自定义验证码]和[远程协助连接本设备的方式]两项设置。
  2. 第一次练习保持默认：「验证码连接」加临时验证码。
  3. 进入[远程协助]-[开始协助]，在[本设备]区域查看[本设备ID]和[设备验证码]，点[复制并分享]发到主控端。自己练习时，发给你自己即可。

为什么：开关关着时，主控端会提示「设备 ID 错误或不存在」。官方功能页写它默认开启，但帮助页第一步仍要求你确认，所以要看一眼。注意：复制的内容包含设备 ID、验证码、设备系统和所在地区，不要发到群里。

主控端：输入并连接 ​

  • 电脑主控端：进入[远程协助]-[开始协助]，在[伙伴的设备ID]里输入设备 ID 和验证码，点[连接]。
  • 手机或平板主控端：进入[远程协助]，填写[伙伴的设备ID]和[伙伴的设备验证码]，点[开始远控]。

Windows 主控端 4.41.0 及以上支持「智能粘贴」：复制完整的协助信息后进入[开始协助]，会自动填入设备 ID，识别到验证码时会自动使用。点提示里的[关闭自动识别]可以关掉它。

连上后，主控端窗口里出现被控端桌面。电脑主控端右上角有[控制中心]；手机主控端有侧边工具栏。被控端会弹出[被远程协助]提醒，让你知道有人连进来了。

操作一次，断开并收尾 ​

  1. 在被控端桌面上打开一个窗口（例如文件管理器），拖动它，再关闭。然后到被控端本地确认：那个窗口确实被打开又关掉了。
  2. 断开远控连接。被控端也可以随时停止授权。
  3. 被控端回到[设置]-[安全]，关闭[允许他人远程协助]。官方建议日常关闭它。

跑通后看一眼[开始协助]页下方的[最近连接]。电脑端最多保留 8 条，可以一键复连或[清空记录]。

日常用法 ​

配置无人值守 ​

按你的情况挑着做：

你想要做什么在哪台设备
连自己的设备两端登录同一账号，主控端主页面点[进入桌面]两端
重启后仍在线[设置]里开启[开机自动启动]被控端
跨账号、不用每次报码[设置]-[安全]里设[自定义验证码]，选「仅使用自定义验证码」或「同时使用两种验证码」被控端
主控端少输验证码[远程协助]-[收藏设备]里点[添加收藏设备]主控端
每次连接都要人点同意把验证方式改成「双重验证」Windows 被控端
防止本地被改设置右上角[更多]-[安全锁定]，设 8 到 16 位安全密码Windows、macOS

三点说明：

  • 收藏列表按账号云端同步，但验证码只记录在本机。换了主控端要重新输入。
  • 安全锁定需要 Windows V4.11.0、macOS V4.38.0 及以上。在[设置]-[安全]-[客户端锁定]里，可以开「远程协助本设备期间，自动锁定客户端」。出处见如何设置客户端安全锁定。
  • Windows 被控端「允许同账号连接」的开关名，本页读到的官方帮助页没有写明，以[设置]-[安全]页为准。

远程开机 ​

前提：先读「核心概念」里的四个条件。操作分五步，前三步在被控端。

  1. 放行客户端。在[设置]-[开机自动启动]里开启[允许通过远程开机启动]。配过 WOL 的点[我确认已完成配置]，没配过的点[开始配置]。
  2. 设置网卡。客户端会自动检测网卡，支持但没开启时按引导一键开启。手动路径：在网卡「属性」的「高级」选项卡里开启「关机网络唤醒」「魔术封包唤醒」或「唤醒魔包」，再在「电源管理」选项卡勾选「允许此设备唤醒计算机」。不同网卡的选项名不一样。
  3. 设置辅助设备。用手机端扫码进入引导，指定一台和被控端同一局域网的 Windows、macOS 或 Android 设备，登录同一账号。Android 设备还要在[我的]-[设置]里开启[远程开机支持 Wake On LAN]，并一直接着电源。
  4. 设置主板 BIOS。开机时按 Del 或 F2 进入，找到并开启 WOL 选项。选项名因品牌而异，认这几个关键词：唤醒、开机、wake、WOL、PCIe、ACPI。联想、戴尔、华硕、技嘉、惠普都有官方教程。
  5. 测试。回到引导点[开机测试]，等设备上线。

成功后，登录同一账号的主控端上，这台设备旁会出现[远程开机]按钮。家里没有闲置设备时，部分型号的路由器可以当辅助设备，见哪些路由器可作为开机辅助设备。出处见如何设置远程开机。

用手机控制电脑 ​

  1. 手机端主页面点[进入桌面]。
  2. 横过手机。官方说明里写明，进入远程桌面后可以旋转屏幕，便于操作。
  3. 用侧边工具栏调功能，包括[操作]、[键盘]、[显示桌面]、[展示所有窗口]。

两种鼠标方式，在[操作]里切换：

方式效果
[屏幕触控]点哪里，鼠标就被移到哪里并点击，以触摸点为准
[鼠标指针]屏幕上始终显示鼠标指针，点击和移动作用于指针所在位置

四条常用技巧：

  • 办公快捷键：进入[操作]-[启用按键映射]，选[办公常用]方案。
  • 接实体键盘鼠标：用蓝牙或线连到手机，并关闭【平板触控模式】，开关在右侧「操作」里的「屏幕触控」。iPhone 要打开系统的「辅助触控」，iPad 反过来要关闭它。
  • 只看进度：点侧边工具栏的[小窗模式]。Android 要给[悬浮窗]权限；iOS 需要 18 及以上并开启[自动开启画中画]。同一时间只有一台设备能开小窗。
  • 解锁被控端：在工具栏[安全]里开启[自动解锁被控端]。

传输文件、同步剪贴板、传声音 ​

方式能用在哪怎么做
[文件传输]入口仅同账号远控设备详情页进入，选文件和接收目录后发送
拖拽同账号远控、远程协助把文件拖进远控窗口，在目标文件夹处松手
复制粘贴同账号远控、远程协助在一端复制，到另一端粘贴

手机上的[文件传输]有三个按钮：[发送照片&视频]（选好后点[添加]）、[发送文件]（选好后点[打开]）、[从电脑下载文件到手机]（勾选后点[下载]）。下载的文件在[已接收]或手机文件管理器的[UU远程]文件夹里。

三点注意：

  • 远程协助时没有独立的[文件传输]入口。要拖拽，主控端和被控端都要在[设置]-[安全]里开启[被远程协助时允许文件互传]。被控端往外发文件时，把文件拖到右下角的 UU 悬浮球，再点[发送]。
  • 剪贴板：在远控界面[操作]-[安全]里开启[同步剪贴板]。手机和 Windows 之间只同步纯文本，长文本最多 6 万个汉字。
  • 声音：开启[被控端静音运行]后，声音只在主控端出，被控端不出声。反过来把手机麦克风的声音送进被控端，叫「麦克风直连」，在[控制中心]-[外设]-[麦克风]里开，被控端只支持 Windows。

官方推荐两端都用 4.43.0 及以上。出处见如何进行文件传输。

同时看多块屏或多台设备 ​

  • 切换屏幕：被控端接了多台显示器时，远控窗口顶部会出现多个页签。点页签切换；按住页签拖出，可以变成独立窗口。
  • 凭空加屏：被控端只有一块屏幕时，点顶部栏的 [ + ] 创建虚拟屏。最多创建 3 个，物理屏加虚拟屏总共最多 5 个。
  • 合成一块大屏：在[控制中心]里点[切换使用超级屏]，被控端的全部桌面会集中显示在一块虚拟屏上。

限制：创建虚拟屏和超级屏只支持同账号远控；主控端必须是 Windows 或 macOS 电脑；被控端要求 Windows 10 或 macOS 11.0 及以上，两端建议 4.35.0 及以上。多台设备方面，官方多屏协作页写明可以同时控制多台电脑，但手机端同一时间只能控制一台。出处见如何进行多屏幕控制。

在会议室或公共场合开防窥 ​

  1. 连接后，电脑主控端进[控制中心]-[安全]；手机主控端进[操作]-[安全]。
  2. 在[被控端防窥模式]里选一档：
    • [隐私屏保]：被控端屏幕上盖一层屏保图片。隐私功能页把这一档写作[黑屏防护]。
    • [关闭显示屏]：直接熄掉被控端的物理屏幕。只有 Windows 被控端支持。
  3. 需要时勾选[被控端静音运行]和[被控端自动锁屏]。后者让远程一结束，被控端就自动锁屏。

人在被控端旁边时，可以按快捷键临时解除防窥：Windows 按 Ctrl + Alt + P，macOS 按 control + option + P。解除后被控端会自动锁屏，下次连接防窥照常生效。出处见如何开启或关闭防窥模式。

调画质、帧率、分辨率 ​

  • 入口：连接后点右上角[控制中心]，菜单里有[分辨率]、[画质]、[窗口]、[声音]、[安全]。
  • 开真彩：电脑端在【操作中心】-【显示】里选【真彩】；手机端在【操作】-【显示】里选【真彩4:4:4】。
  • 开 HDR：在[控制中心]-[画质]里开启[HDR]。只有 Windows 控 Windows 时可用，两端都要支持 HDR。

找不到选项时，按顺序排查四件事：

  1. 会员档位。真彩、HDR、144 帧列在 VIP 权益里，见「费用」一节。
  2. 显卡。被控端是 AMD 显卡时不支持真彩。
  3. 主控端系统。Android 主控端都不支持真彩，iOS 主控端都支持。
  4. 负载。「原画」和「真彩」不能同时生效；被控端 GPU 负载过高时真彩会失效。

卡顿时，官方建议降画质、帧率后再试。出处见哪些设备可开启真彩模式 和 HDR 帮助页。

玩游戏：接手柄、用按键映射 ​

接手柄：Windows 主控端支持 Xbox 全系和 PS5 手柄；Android、iOS 主控端还支持 PS4、Switch Pro、Joycon。被控端最多同时接入 4 个手柄，陀螺仪和触摸板暂不支持。用按键映射：进入[操作]-[启用按键映射]，选官方方案，或在[编辑当前方案]里改键位。需要移动视角时加一个「轮盘」当虚拟摇杆；需要一键连招时用「宏按键」。出处见如何使用手柄 和 按键映射功能页。

把平板或手机当无线副屏 ​

  1. 主屏（Windows 或 macOS 电脑）和副屏（Android 或 iOS 手机、平板）都升级到 4.46.0 及以上，登录同一个账号。
  2. 副屏保持客户端在前台，并且没有在远控或传文件。
  3. 在电脑主界面顶部点[无线副屏]，从列表里选手机或平板。状态显示[已连接]即成功。
  4. 在主屏点已连接的设备，可以调分辨率、缩放、方向、画质、帧率。

限制：只能扩展一块副屏，不支持镜像，副屏不出声，电脑不能当副屏。出处见无线副屏怎么用。

帮父母或同事做远程协助 ​

流程和「10 分钟跑通第一件事」一样。多三个技巧：

  • 对方没装客户端：把精简版的 .exe 发给对方。它免安装、免登录、双击即用，只支持 Windows，只能当被控端。每次远控结束后验证码自动刷新。
  • 经常帮同一个人：在[远程协助]-[收藏设备]里添加对方，并让对方设一个自定义验证码。
  • 不想误点对方的电脑：连接后在[控制中心]-[工具]里点[启用观看模式]，键鼠和触控不再发往被控端，可以用[画笔]批注指出该点哪里。电脑按 Ctrl + Shift + V 切回，手机在[操作]里关掉[仅观看]。

真实用例 ​

在外面接着看编码 agent 的进度 ​

你在家里的高配电脑上跑着 Claude Code 或 Codex 这类命令行 agent，人已经出门。远程控制能做到的是：

  1. 用平板或手机登录同一账号，点[进入桌面]，或者进[设备详情]-[终端]直接接到那个终端会话。
  2. 官方终端帮助页写明，带 TUI 界面的工具可以直接点击终端页面操作，例如切换会话。你据此能看到 agent 的输出，并在它等确认时敲下一步。
  3. 临时去干别的，把画面收成[小窗模式]；或者直接关掉，回来再重新接入同一个会话。

agent 本身怎么用，见 Claude 和 Codex。从手机上批准 agent 下一步的另一种做法，见 T3 Code。

把家里的电脑当远程工作站 ​

官方远程办公页列了三个开发场景：查看日志、执行指令用终端；访问内网服务与调试环境用端口映射（把远端的 TCP 服务映射到本机端口，只支持 TCP）；在远端开发机运行 AI 编码任务、随时接入查看，用远程桌面加终端。环境留在原开发机上，你不用在外面重新搭一套。两项能力的入口都在[设备详情]页，「终端」进[终端]，端口映射进[更多]-[端口映射]，都只支持同账号远控，两端要求 Windows 或 macOS 电脑。出处见远程办公功能页、终端怎么用 和 端口映射怎么用。

官方 CLI：用脚本查询在线设备 ​

官方帮助中心有一页讲 uuyc-cli，可以在终端里查询设备、发起远控、管理远程协助，并支持 --json 输出。新版命令要求 Windows 主控端 V4.43.0 及以上。macOS 主控端保留原有的 CLI 能力，但官方说明页写明新版命令暂未同步到 macOS，所以下面的命令表和脚本不要直接当作 macOS 的操作指引。Windows 默认不把它加入 PATH，怎么找到它见官方 CLI 教程。

下表是 uuyc-cli --help 实际列出的命令，抄自 Windows 版 4.48.1.5606（2026-11-24 实测）。--json 是各个子命令自己的选项，不是全局选项。

命令作用（译自 --help 原文）
uuyc-cli device ls（别名 list）列出可连接的设备
uuyc-cli device info查看设备详情
uuyc-cli device connect <设备 ID>按设备 ID 连接远端设备
uuyc-cli device disconnect [设备 ID]断开连接；不带 ID 则断开全部
uuyc-cli device status查看连接状态
uuyc-cli assist id取得远程协助 ID
uuyc-cli assist reset-code / set-code刷新 / 自定义远程协助验证码
uuyc-cli assist allow on / off开启 / 关闭远程协助
uuyc-cli assist start <协助 ID> [验证码]发起远程协助；可改用 --code-stdin 从标准输入读验证码
uuyc-cli assist status查看远程协助状态
uuyc-cli term -d <设备 ID> new 等远端设备上的终端会话：new / attach / ls / has / rename / kill
uuyc-cli lterm new 等本机终端会话，子命令同上
uuyc-cli status应用诊断信息

user、cloudpc、echo 三个子命令本页没有展开。--help 还列出了一组标为 deprecated 的旧式参数（如 --list-devices、-n,--connect），新脚本不要再用。

下面这段脚本只做只读查询：列出同账号下在线设备的 ID。命令、参数和 JSON 字段取自官方 CLI 页，并已在 Windows 版 4.48.1.5606、Node 24.16 上实际运行通过：正常时退出码为 0，缺参数为 2，找不到可执行文件为 1。返回的每一项除 deviceId、isOnline 外，还有 deviceName、platform、lastSeen。文件名必须用 .mts：Node 只有见到 .mts（或同目录有 "type": "module" 的 package.json）才按 ES module 解析，存成 .ts 会直接报错。

ts
// 用法：node uuyc-online.mts "<uuyc-cli 可执行文件的路径>"
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const execFileAsync = promisify(execFile);
// 官方约定：device list 的结果在 data.items 里，每项含 deviceId 与 isOnline
interface DeviceListResult {
  data?: { items?: { deviceId: string; isOnline: boolean }[] };
}

const [cliPath] = process.argv.slice(2);
if (!cliPath) {
  console.error('用法: node uuyc-online.mts "<uuyc-cli 可执行文件的路径>"');
  process.exit(2);
}

try {
  const { stdout } = await execFileAsync(cliPath, ['device', 'list', '--json'], {
    encoding: 'utf8',
  });
  const result = JSON.parse(stdout) as DeviceListResult;
  const online = (result.data?.items ?? []).filter((item) => item.isOnline === true);
  const ids = online.map((item) => item.deviceId);
  console.log(ids.length ? `在线设备 ID：\n${ids.join('\n')}` : '没有在线设备');
} catch (err) {
  // 官方 CLI 页列出的退出码：101 未登录；102 无法连接主应用或终端服务（这两种失败本页没有复现）
  const code =
    err !== null && typeof err === 'object' && 'code' in err ? String(err.code) : '未知';
  console.error(`device list 执行失败（退出码 ${code}）。先确认主应用已启动并已登录。`);
  process.exit(1);
}

三点提醒：

  • device connect 是异步命令，返回成功只代表请求已提交，要继续查 device status --json。
  • 远程协助验证码属于敏感信息，官方建议用 --code-stdin 传入，避免留在命令历史里。
  • 本页作者没有在官网找到面向第三方的开放 API 或 SDK 文档。不要把它当成开放平台来集成。

给新人的操作清单 ​

防止别人连进来：

  1. 设备 ID 和验证码只给核实过身份的人。 官方资讯页的原话是，任何以「退款验证」「账户解冻」「客服排障」为由索要设备码或验证码的陌生请求，都不应接受。
  2. 用完就关。 在[设置]-[安全]里关闭[允许他人远程协助]。官方建议日常关闭。
  3. 保持临时验证码自动刷新，或改用「双重验证」。 这是官方帮助页的注意事项。
  4. 固定验证码只设在自己的设备上，不要复用其他密码。 后半句是本页建议，不是官方原文。带验证码的内容不要发到群里。

防电信诈骗。 远程协助类软件常被冒充客服的诈骗利用。官方资讯页提醒，把设备 ID 和临时验证码发给协助者之前，要通过电话或熟人聊天再次确认身份，陌生人索要验证码时直接拒绝。新华网 2025-04-23 的一篇报道引述天津市反诈中心的预警：接到自称客服的陌生电话，对方让你点不明链接、扫码下载 App 时，不要做；操作中感觉不对劲，立刻停手。

限制连进来的人能做什么：

  1. 账户密码、支付验证码由电脑主人自己输入。 协助者只说明位置和流程，这是官方资讯页的要求。
  2. 给无人值守的设备开安全锁定。 防止别人在被控端本地关掉开关。
  3. 开[被控端自动锁屏]和[被控端防窥模式]。 远程一结束，被控端就锁屏。
  4. 用完精简版就删掉 .exe。 它免安装，删除文件即卸载。

管好账号和设备：

  1. 怎么断开已绑定的设备。 官方多屏协作页写明，可以随时删除闲置设备；具体入口路径该页没有文字说明，以客户端设备列表为准。另外，不要在陌生设备上长时间登录，这是官方远程办公页的提醒。
  2. 会员只在客户端内买。 官方写明没有第三方购买渠道。发现漏洞也走官方渠道，通过网易安全中心提交，不要公开漏洞细节。

故障排查 ​

连不上时先查什么 ​

  • 完全连不上：被控端是否开机、联网、客户端在运行；[允许他人远程协助]是否已开，或两端登录的是不是同一个账号。
  • 能连上但很卡：到主控端[控制中心]降低画质和帧率；网络差时不要开真彩和 HDR。
  • 公司或学校网络连不上：网络可能限制外网访问。在[设置]-[网络]-[代理设置]里选[系统代理]或[手动设置]，前提是你已有可用代理。出处见网络代理怎么设置。
