AI/LLM 新手？ 先复习这些概念：

路径 2: 添加 AI 功能

使用 JavaScript/TypeScript 将 AI 能力集成到你的应用中。

第 1 周

API 基础

了解如何通过 API 与大语言模型 (LLM) 通信。学习身份验证、模型和基于 Token 的定价。

API 对比OpenAIAnthropicLLM 基础
第 1 周

流式 UI (Streaming UI)

用户期望 AI 能“打字”出答案。学习使用 Vercel AI SDK 和 Server Sent Events 实现流式传输。

流式指南Vercel AI SDK聊天 UI 组件AI 聊天机器人项目
第 2 周

RAG 模式

教 AI 了解你的数据。实现检索增强生成 (RAG)，使 AI 的回答基于你的文档。

RAG 模式EmbeddingsLlamaIndex TSRAG 搜索项目
第 2 周

工具调用与智能体

将 AI 从聊天机器人转变为执行操作的智能体。实现函数调用和工具使用模式。

工具调用MCP 协议生成式 UI智能体模式

生产级功能

将所有内容组合成完善的功能：智能表单自动补全、文档问答机器人和错误处理。
