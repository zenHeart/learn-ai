# 视频摘要最佳实践

从 50+ 视频摘要提炼中总结的常见误区与改进方法。

## 1. 摘要写作的 5 大误区

### 误区 1: 摘要 = 视频概述

**症状**: "本视频主要讲 XXX, 然后讲到 YYY, 最后讲到 ZZZ"
**问题**: 流水账, 无价值判断, 读者读完不知道该不该花 1 小时看原视频
**改进**: 一句话总览必须回答"为什么该看 / 不该看", 例: "如果你用过 Claude Code 但没听过 auto mode, 这 5 分钟值得; 否则跳过"

### 误区 2: 把整个视频"压缩"成摘要

**症状**: 摘要 5000 字, 与 transcript 等长
**问题**: 摘要失去意义
**改进**: 严格控制 800-1500 字。原则: "每个要点都要能塞进一个 tweet"

### 误区 3: 时间码是装饰

**症状**: 摘要里写"视频 1 分钟处提到", 但点击跳到 1 分钟是无关内容
**问题**: 失去可定位价值
**改进**: 用脚本校验每个时间码 → 必落在 segment 范围内

### 误区 4: 关键帧引用与内容不匹配

**症状**: 摘要写"代码编辑器显示 Vite 配置 frame_028", 但 frame_028 不是编辑器
**问题**: 信任崩塌
**改进**: 关键帧必须人工或 LLM 视觉确认后才能引用

### 误区 5: 哲学段落当技术结论

**症状**: 摘要里写"Lydia 说 Depends on the engineer", 显得空泛
**问题**: 读者无法行动
**改进**: 哲学必须配 1 个"可立刻试" 的具体动作

## 2. 时间码使用的 3 条铁律

### 铁律 1: 每个时间码必须可点

[00:05:30] 必须能在 index.html 中跳到 5 分 30 秒。如果跳到无关内容, 就删掉这个时间码。

### 铁律 2: 多个时间码 → 选最早

同一个概念出现 3 次(00:05, 00:15, 00:30), 用 00:05。

### 铁律 3: 模糊时间码是毒药

绝对不写"大约" "差不多" "可能" "估计"。只有精确时间码可定位。

## 3. 摘要长度的科学

| 视频长度 | 摘要字数 | 核心要点数 | 关键术语数 |
|---|---|---|---|
| < 15 分钟 | 200-400 | 3-5 | 3-5 |
| 15-60 分钟 | 500-1000 | 5-8 | 5-10 |
| 1-2 小时 | 800-1500 | 6-10 | 8-15 |
| > 2 小时 | 1500-3000 | 8-12 | 10-20 |

理由:

- 摘要字数 < 视频字数的 10%(否则失去压缩意义)
- 核心要点 ≤ 12(超过人类短期记忆上限)
- 关键术语 ≤ 20(超出会变成 glossary)

## 4. 何时不用本 skill

- **3 分钟以下的视频**: 直接人工看, 摘要时间 > 观看时间
- **纯音乐/纯画面视频**: 无 transcript 价值
- **隐私/合规视频**: 必须人工审核才能发布
- **已过期视频**(>2 年): 模型与代码可能已过时, 摘要价值低

## 5. 增量更新的最佳实践

**场景**: 已生成的 summary.md 被人指出错误, 需要修订。

1. 永远**只改 summary.md**, 重新跑 build-html.py
2. **不要**改 transcript.txt 或 segments.jsonl(它们是事实, 不是观点)
3. 修改时**保留原时间码**, 加 `**修正**: ...` 注释
4. 大改时(>50% 内容变化) 建议改完后跑 `validate_summary.py` 校验

## 6. 多人协作的版本约定

- `summary.md` 走 Git, 每次修订有 commit
- 关键帧引用 (`frame_NNN.jpg`) **必须**用相对于视频的路径, 不能用绝对路径
- 时间码格式 `HH:MM:SS` 不能改成 `MM:SS`(虽然短但易混淆)
- 术语表"中英对照" 的中文名 1-2 字(避免"自动驾驶系统" 这种)

## 7. 与其他资产的联动

视频摘要的产物(summary.md) 可以进一步成为:

- 博客文章(添加开头 + 案例 + 行动建议)
- 课程大纲(根据时间轴主题展开)
- 知识库条目(用关键术语做索引)
- 训练数据(RLAIF / DPO 用)
- 引用材料(在 PPT / 论文中 link 到具体时间码)

`summary.md` 是资产, 不是终点。

## 8. 反例: 什么样的摘要算失败

```markdown
## 一句话总览
本视频讲 Claude Code 的使用技巧。

## 核心要点
- [00:00:00] Claude Code 是个 AI 编程工具
- [00:10:00] 视频里讲了很多功能
- [00:20:00] 还有权限相关的部分
- [00:30:00] 演示了一个游戏
- [00:40:00] 总结

## 时间轴主题
- [00:00:00 - 60:00] 整个视频

## 关键术语
- Claude Code: AI 工具
- Skills: 技能
```

**为什么失败**:

- 一句话总览 14 字, 没说价值
- 核心要点都是"视频里有", 没有"用户该怎么做"
- 时间码 00:00:00 → 60:00 是一整段, 没分段
- 关键术语 2 个太少, 且没有具体内容
- 全部是描述视频, 没有任何"读者能用上的洞察"
