# 全景图：三层如何协同

<v-click>

```
第一步：Prompt（任务说明书）
└─ 清晰指令：角色 + 约束 + 输出格式

第二步：Context（项目笔记本）
└─ 精准注入：只给 AI 当前任务需要的内容，让 AI 自行探索

第三步：Harness（工作环境）
└─ 工具链：读文件 / 写代码 / 跑测试 / 开 PR
   + 记忆：Session / Project / User
   + 循环：执行 → 观测 → 修正 → 验证
```

</v-click>

# 本章小结：三层协同

<v-clicks>

1. **三层不是相加，而是相乘**：Prompt、Context、Harness 任一层缺位都会拖垮系统

2. **协同方式很清楚**：Prompt 定目标，Context 给证据，Harness 管执行与验证

3. **实战检查一张表**：ICIO 完备、上下文精准、工具闭环到位，才是可信赖协作

</v-clicks>
