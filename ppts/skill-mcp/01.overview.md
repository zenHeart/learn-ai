# AI 资产全景 · 七种武器

<div class="grid grid-cols-2 gap-x-6 gap-y-2 mt-4 text-sm">

<div class="table-scroll col-span-2">

| 资产 | 一句话定位 | 谁触发 | 装哪 |
|---|---|---|---|
| **Rules / Memory** | 常驻的团队约束与项目背景 | 自动进 Context | `AGENTS.md` · `CLAUDE.md` · `.claude/rules/` |
| **MCP** | 连进外部系统的「手脚」 | 模型自主调 | `.mcp.json`（本地/远程 Server） |
| **Skill** | 固化一类活的「工序手册」 | 模型读 description 自激活 / `/name` | `.claude/skills/<name>/SKILL.md` |
| **Command** | 显式触发的快捷入口 | 用户敲 `/cmd` | `.claude/commands/` |
| **Subagent** | 独立上下文的「分身」 | 主 agent 派活 | `.claude/agents/` |
| **Hook** | 必然执行的强制动作 | 事件触发（如 edit 后） | `settings.json` hooks |
| **Plugin** | 把上面打包分发的「整套装备」 | 安装即生效 | 内部 npm / marketplace |

</div>

</div>

<div class="mt-3 p-2 theme-combo text-sm">
🔑 <strong>MCP = 能力（伸手）· Skill = 工序（肌肉记忆）</strong>，是本期主角；其余五种是约束、入口与打包方式。
<br><span class="text-xs text-slate-500">注：Skill 是<strong>按需加载、可复用</strong>的资产，区别于一次性的对话提示词（prompt）—— 造一次，之后自动生效、跨会话复用。</span>
</div>

# 怎么选？一句话口诀

<div class="mt-6 grid grid-cols-2 gap-5 text-sm">

<div class="col-good">

### ✅ 按「需要什么」选

* 要**伸手**到外部系统（查单 / 读日志 / 提 MR）→ **MCP**
* 要 AI **按团队规矩走流程**（发版 / 审查 / 自验证）→ **Skill**
* 要**每次都生效**的硬约束（命名 / 风格 / 中文优先）→ **Rules**
* 要**必然执行**的动作（改完就 lint）→ **Hook**
* 要**隔离上下文**并行干（并行审 PR）→ **Subagent**

</div>

<div class="theme-combo">

### 🎯 决策只看两件事

1. **是「能力」还是「规矩」？**
   能力缺 → MCP；规矩缺 → Skill / Rules
2. **谁该触发它？**
   模型自己判断 → Skill / MCP
   每次都要 → Rules / Hook
   我手动 → Command

<div class="mt-3 text-xs text-slate-500">
大多数真实任务是<strong>组合</strong>：Skill 编排顺序 + MCP 提供能力 + Rules 兜底约束。
</div>

</div>
