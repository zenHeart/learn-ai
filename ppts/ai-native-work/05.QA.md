# Q1 · 安全与权限

| 原则 | 做法 |
|------|------|
| 最小权限 | 诊断默认只读；构建默认不发布 |
| 人守底线 | 合并、生产发布、对外口径人定 |
| 凭据不进资产 | Skill / 文档不写密钥 |
| 失败即停 | 预检/读回不一致不得称成功 |

# Q2 · 和「直接跟大模型聊」差在哪？

一句话：**裸聊缺手脚、缺工序资产、缺机器验收、缺持续复用。**

| | 裸聊 | Agent + 工作流 + nn-ai |
|--|------|-------------------------|
| 内网系统 | 通常碰不到 | MCP 手脚 |
| 重复任务 | 每次重讲 | Skill 复利 |
| 验收 | 主观 | 命令 / 读回 / CI |

# Q3 · 如何衡量是否放大效能？

与飞轮旁「最小度量」相同：

- **结果**：重复劳动小时、交付周期、返工  
- **过程**：人工介入次数、Skill 复用率、误触  

固定 **1+1 指标**，周复盘；没有指标就没有第四步迭代。
