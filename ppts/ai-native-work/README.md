## 讲者轨（时间盒）

### 45 分钟必讲轨

1. 引子主链（链条→痛→阶→「有了 AI」固化 Skill→分工→回扣三件事）→ 公式 → 目标  
2. 理念：成本 + 证据锚点 + D/D/D（零基 20 秒）  
3. 方法：能力层组件 + 反模式 + 识别四问  
4. 资产：飞轮组件 + Skill 四步 + **场景地图**（**跳过附录三表**）  
5. 实操：路径 A **或** B 一条演示节拍 + First Action  
6. 带走清单 + QA  

### 55 分钟完整轨

- 加上路径 A+B 演示（或一 live 一录屏）  
- 委托启发式 + 一天剧本  
- 适应张力 + nn-ai 真实时间线 + `/bugfix` 案例  
- 附录仅闪过「会后看」
