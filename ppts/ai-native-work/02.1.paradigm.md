# Agent 时代：四类成本明显变低

| 成本类型 | 以前 | Agent 之后 |
|----------|------|------------|
| **起草与检索** | 人肉搜文档、写初稿 | 秒级起草、跨系统检索（有工具时） |
| **格式化劳动** | 改格式、重命名、填表 | 可脚本化 / Skill 化 |
| **多轮试错中的机械部分** | 人反复改细节 | Loop + 验收命令代劳部分迭代 |
| **知识搬运** | 复制粘贴、口头同步 | 记忆文件 + 共享 Skill / MCP |

**变低的是「执行与搬运」；没有自动变低的是「目标、标准、风险、取舍」。**

# 外部锚点：提效长什么样

（对标一线组织公开观察，用于对齐预期，不是本公司 KPI）

| 观察 | 含义 |
|------|------|
| **高频使用 ≠ 全权委托** | 多数人仍主动监督；「完全放手」往往只占一小部分工作 |
| **提效常见形态是产出量↑** | 同样工时做更多，而不只是单任务极致提速 |
| **相当比例是「以前不值得做」的事** | papercut、探索、跨栈、文档/测试等被激活 |
| **可验收、低风险、定义清晰** 的任务更适合委托 | 与后文识别四问、委托启发式一致 |

::: tip
复利 = **做得更快** + **做得更宽** + **标准可复用**。
:::

# 分工怎么定：谁定义 · 谁执行 · 谁验收

| 角色 | 更重要的事 | 可更多交给 Agent 的事 |
|------|------------|------------------------|
| **人** | 定义问题、定标准、守边界、做取舍 | — |
| **Agent** | — | 检索、起草、批量执行、按清单自检 |

::: tip 一句话
个人效率上限 ≈ 人的决策质量 × Agent 执行面宽度。
:::

# 旧流程套个 AI 壳，还是干脆重新设计？

::left::

### 套壳

- 流程不动，多开一个聊天窗
- 输出仍靠人「感觉做完了」
- 成功经验在聊天记录
- 工具越多越乱

::right::

### 重新设计

- **假设 Agent 能做尽做**，人只守例外与决策
- **I/O + 机器可执行验收** 写进定义
- 成功经验进 Skill / kit / 记忆文件
- **缺哪一层补哪一层**

::: tip
先改工作定义，再堆工具——不是反过来。
:::

# 如何适应：三条原则

1. **先改工作定义，再堆工具**  
   把任务写成：输入 → 步骤 → 输出 → 验收，而不是「帮我弄一下」。

2. **人守决策与风险，Agent 扩执行面**  
   合并、发布、对外口径、合规——默认人定。

3. **一次做成可复用资产**  
   第二次还要讲同样长 prompt = 还没适应。应沉淀为 Skill / 记忆 / 口令。

# 人与 Agent 的分工口诀

::left::

### 人 · Decide / Define / Defend

1. **Decide** — 做不做、做到哪  
2. **Define** — I/O 与验收  
3. **Defend** — 权限、发布、合规  

::right::

### Agent · Discover / Draft / Do

1. **Discover** — 搜、读、汇总  
2. **Draft** — 方案与草稿  
3. **Do** — 在授权内执行与自检  

**交接物：** 清晰 I/O + 可机器执行的验收 + 权限边界。

---

# 适应时要注意（不是恐吓）

| 张力 | 健康做法 |
|------|----------|
| **监督能力** 可能随「全交给 AI」变钝 | 故意保留一部分手写 / 手审练习 |
| **同事协作变少**（问题先问 Agent） | 复杂与语境题仍找人；资深做 taste 与带教 |
| **只会找会写 Skill 的人** | 统一 **@nn/ai-kit** 分发；有 Evals 再合入 |
| **角色从写作者 → 编排者** | 练定义、验收、并行管理，而不是只练打字速度 |

::: tip
成熟用法承认张力，再用机制对冲——不是假装只有好处。
:::

# 理念回看报销

在报销链里：

**变便宜的是** 识别、命名、汇总、上传的执行  
**变贵的是** 标准是否一致、异常谁拍板、读回是否算成功

→ 与全场公式同一句话：**执行塌陷，决策与标准更关键。**

# 本章小结：理念

<v-clicks>

1. **变低的是执行与搬运；变贵的是决策与标准**
2. **个人放大**靠决策质量 × Agent 执行面宽度
3. **提效形态**：更快 + 更宽 + 可复用（非全权委托神话）
4. **适应**：先改定义再堆工具 · 人守风险 · 一次做成资产 · 正视张力

</v-clicks>
