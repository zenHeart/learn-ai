# 网易UU远程学习地图

> **网易UU远程**（网易出品的远程控制软件）让你人在外面，也能操作自己的电脑，或帮别人修电脑。它走「画面串流」路线：两端装上客户端，登录同一个账号，或报「设备 ID + 验证码」，就能把另一台设备的桌面接到眼前。
>
> 本页是**产品全景 + 决策表**。装与用都在[上手教程](./uu-remote)。界面文字与数字来自 2026-11-24 打开的网易官方页面。

## 写给谁 / 先决条件 / 非目标

- **写给谁**：会写前端代码、用过命令行，但没接触过远程控制软件的人。
- **先决条件**：两台联网设备，一个网易UU远程账号。各平台的系统要求见教程的「安装」一节。
- **非目标**：
  - 不讲内部实现。官方没有公开建连流程、编解码器、协议和服务器架构。
  - 不讲 UU加速器、MuMu模拟器、网易千千壁纸。它们只是官网「友情链接」里的产品。
  - 不展开「云设备」（游戏云电脑、AI 云电脑）。它们是官网导航里另一组产品。
  - 不对比其他远控软件的功能和价格。本页没有打开它们的官方页。

### 容易撞名

- **UU远程 ≠ UU加速器。** UU加速器是游戏加速器，在官网「友情链接」里，和本产品无关。容易混淆的一处：官方路由器文档里，让路由器给 UU远程 当「开机辅助设备」时，装的插件叫「网易UU加速器插件 WOL 版本」。
- **UU远程 ≠ MuMu模拟器、网易千千壁纸。** 同在友情链接里。
- **「GameViewer远程」是旧名。** 官方公告页（页面日期 2024-12-10）写明「GameViewer远程」正式更名为「网易UU远程」，见[官方公告](https://uuyc.163.com/blog/20241206/41377_1198665.html)。
- **VIP ≠ 全球 VIP。** 全球 VIP 多一项「全球远控节点」。官方常见问题写明，被控端在境外，或主控端开着 VPN 被识别为境外时，会提示开通全球 VIP。价格与权益见教程的「费用」一节。
- **「安全密码」不是连接密码。** 它给客户端上锁；连接靠验证码。
- **「安卓屏幕共享」不是远程控制安卓手机。** 对方只能看、听、批注，不能操控。

## 它解决什么问题

### 没有它 vs 有它

| 场景 | 没有远程控制 | 用网易UU远程 |
|---|---|---|
| 文件落在关机的家里电脑里 | 只能回去开机再取 | 远程开机后用文件传输取回（要事先配好唤醒条件） |
| 父母的电脑出问题，你在外地 | 靠电话一步步描述 | 父母报设备 ID 和验证码，你直接操作 |
| 家里电脑在跑编译或 agent | 人必须守着 | 手机上看进度、敲下一步；终端会话断开后可以重接 |
| 想在大屏上看电脑画面 | 把电脑搬到电视旁 | 用电视版远控，或把平板接成无线副屏 |

### 与替代方案对比

只列本页能核实的内容。

| 方案 | 怎么连 | 适合谁 | 本站去向 |
|---|---|---|---|
| 网易UU远程 | **画面串流**：两端装客户端，登录同一账号，或报设备 ID 与验证码 | 想装上就用，不想自己配网络的人 | 本目录 |
| Tailscale 加系统自带远程桌面 | 先在**网络层**把设备组成一个私有网络，再用系统自带的远程桌面连过去 | 愿意自己配置、想用系统远程桌面的人 | [Tailscale](../tailscale/) |
| Cindy | 内置手机远程桌面功能 | 想在一个工具里同时处理手机侧操作的人 | [Cindy](../cindy/) |
| 其他远控软件（ToDesk、向日葵、RustDesk 等） | 本页没有核对它们的官方页，不作对比 | 无 | 无 |

## 快速决策

| 我的情况 | 用什么 |
|---|---|
| 帮同事或父母临时处理一次电脑问题 | 远程协助：对方报「设备 ID + 临时验证码」 |
| 对方没装客户端，也不想装 | 发[UU远程精简版](https://uuyc.163.com/features/sos/)，仅限 Windows 被控端 |
| 自己的电脑，想随时连 | 两端登录同一账号，主控端点[进入桌面] |
| 自己的电脑关机了也想连 | 先配远程开机：网卡、主板、局域网辅助设备三样缺一不可 |
| 被控电脑是 Mac | 先在 Mac 上开[允许本设备被控]和两项系统权限 |
| 在外面用手机看编码 agent 的进度 | 同账号远控，进[设备详情]-[终端]，或全屏桌面加小窗模式 |
| 只想取一个文件 | 同账号用[文件传输]入口；远程协助用拖拽或复制粘贴 |
| 在会议室或咖啡馆操作 | 开[被控端防窥模式]和[被控端自动锁屏] |
| 公司或学校网络连不上 | 客户端[设置]-[网络]-[代理设置]（前提是已有可用代理） |
| 想要 4K、144 帧、真彩、HDR、多屏控多屏 | 这些是 VIP 权益，官方公告写 2026-12-01 上线 |
| 想把安卓手机屏幕给别人看 | 安卓屏幕共享，只能看不能控 |
| 更想自己组网、少装一个远控客户端 | 看 [Tailscale](../tailscale/) 页 |
