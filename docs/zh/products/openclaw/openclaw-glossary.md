# OpenClaw 术语表

**OpenClaw** — 自托管多通道 Agent 网关。[openclaw.ai](https://openclaw.ai/)。

**Gateway** — 本机核心进程。Getting started：默认端口 18789。

**Control UI / dashboard** — `openclaw dashboard` 打开的浏览器界面。

**Pi** — 终端 harness。OpenClaw 可用其 SDK。见 [Pi](/zh/products/pi-agent/)。

**通道** — Telegram / 飞书 / 微信等是接入，不是那些 IM 的产品手册。
