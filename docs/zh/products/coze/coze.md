# 扣子编程：搭一个低代码智能体

> 这是一份**教程**。按顺序做完，你会得到一个能对话、能发布的低代码智能体。
>
> 查套餐和渠道用 [速查表](./coze-cheatsheet.md)。工作流 / 知识库 / CLI 用 [Cookbook](./coze-cookbook.md)。词对不上用 [术语表](./coze-glossary.md)。

本指南目标：把扣子从「听说能搭 Bot」用成「能自己发布一个智能体」。

## 先决条件

- 能打开 [code.coze.cn](https://code.coze.cn/)（国内站）。国际站是 [coze.com](https://www.coze.com/)，账号和渠道不要混用。
- 有手机号或抖音账号，用于注册（[注册登录](https://docs.coze.cn/guides_sign_up)）。
- 不要求会写代码。低代码路径官方原文就是「无论你是否有编程基础」。
- 企业员工按套餐走企业/团队入口登录，不要用个人通道硬闯。

## 学习目标

- 分清「扣子」和「扣子编程」该进哪一个。
- 按官方步骤创建一个低代码智能体。
- 写一段能约束模型的人设，而不是只填名字。
- 知道插件不会自动被调用，必须在人设里引用。
- 发布前先在预览区测通。

## 第 0 步：进对网站

| 你以为自己在… | 实际该打开 | 不要打开 |
|----------------|------------|----------|
| 搭智能体 / 工作流 | [code.coze.cn](https://code.coze.cn/) | 豆包、Trae |
| 和现成 Agent 一起办公 | [coze.cn](https://www.coze.cn/) | 本教程不走这条 |
| 看文档 | [docs.coze.cn](https://docs.coze.cn/) | 随机搜索到的 2024 年 Bot 博客 |

官方把低代码项目定义成扣子编程「较为早期的版本」，但 **新建低代码智能体仍然从扣子编程进入**（[about-low-code-project](https://docs.coze.cn/about-low-code-project)、[guides_quickstart](https://docs.coze.cn/guides_quickstart)）。

个人免费版可以先体验。付费档位和积分见 [速查表 · 套餐](./coze-cheatsheet.md#套餐与积分)，不要背死价格。

## 第 1 步：创建一个低代码智能体

以下步骤逐字对应官方「搭建一个 AI 助手智能体」（夸夸机器人）：

1. 登录 **扣子编程**。
2. 顶部选好工作空间，左侧点 **新建项目**。
3. 在 **低代码模式** 区域点 **智能体开发**。
4. 填名称和功能介绍。点图标旁的 **生成** 可自动出头像。也可以切到 **AI 创建**，用一句话让平台起草人设。
5. 点 **确认**。进入编排页：
   - 左：**人设与回复逻辑**
   - 中：**技能**（插件、工作流、知识库等）
   - 右：**预览与调试**

来源：[guides_quickstart](https://docs.coze.cn/guides_quickstart)。

## 第 2 步：写人设，而不是只起名

人设会持续影响所有会话。官方建议写清：角色、语言风格、回答范围。

夸夸机器人的官方示例（可直接用）：

```md
# 角色
你是一个充满正能量的赞美鼓励机器人，时刻用温暖的话语给予人们赞美和鼓励，让他们充满自信与动力。

## 技能
### 技能 1：赞美个人优点
1. 当用户提到自己的某个特点或行为时，挖掘其中的优点进行赞美。
2. 如果用户没有明确提到自己的特点，可以主动询问一些问题，了解用户后进行赞美。

### 技能 2：鼓励面对困难
1. 当用户提到遇到困难时，给予鼓励和积极的建议。
2. 如果用户没有提到困难但情绪低落，可以询问是否有不开心的事情，然后给予鼓励。

### 技能 3：回答专业问题
遇到你无法回答的问题时，调用 Search 搜索答案

## 限制
- 只输出赞美和鼓励的话语，拒绝负面评价。
- 所输出的内容必须按照给定的格式进行组织，不能偏离框架要求。
```

编排页提供 **自动优化提示词**。优化后仍要自己读一遍，不要默认机器改写就是你的意图。

模型选择、单 Agent / 多 Agent、Temperature 等见 [功能概述](https://docs.coze.cn/guides_agent_overview) 和 [设置模型](https://docs.coze.cn/guides_llm)。个人免费版 / 进阶版可用豆包、DeepSeek 等；企业版还可使用方舟上的其他模型。具体名单以控制台为准，不要从旧截图抄模型名。

## 第 3 步：只在模型不够用时加技能

官方口径：模型能力已经够用，就只写人设。模型做不到的事（搜新闻、读 PPT、查内部手册）再加技能。

夸夸机器人加「头条搜索」的官方步骤：

1. 技能区点 **插件** 旁的 **+**。
2. 搜索 **头条搜索**，点 **添加**。
3. 回到人设，输入 `{`，**引用**这个插件。不引用，智能体可能根本不调它。

开场白、用户问题建议、背景图、语音是对话体验，不是能力扩展。需要知识库或工作流时去 [Cookbook](./coze-cookbook.md)。

## 第 4 步：在预览区测，再发布

右侧 **预览与调试** 里先自己聊几轮。

测这几件事：

- 人设有没有被模型忘掉（一上来自称豆包 / DeepSeek 就是没写住人设）。
- 加了插件的问题会不会真的走工具。
- 你明确禁止的内容会不会漏出来。

调试台能看到执行过程。线上已经很慢或不回时，也回这里看，不要先猜模型坏了。

## 第 5 步：发布

官方步骤：

1. 编排页右上角点 **发布**。
2. 填发布记录，勾选渠道。
3. 再点 **发布**。

当前官方默认渠道包括：扣子商店 / 作品社区、飞书、微信（客服 / 服务号 / 订阅号）、掘金、抖音/微信小程序、API、Chat SDK。完整表见 [发布概览](https://docs.coze.cn/guides_publish_overview) 和 [速查表](./coze-cheatsheet.md#发布渠道)。

**不要再选豆包渠道。** 低代码智能体发到豆包的入口已于 **2026-07-01** 下线；已发布的不受影响（[FAQ](https://docs.coze.cn/guides_FAQ)）。

发布会先打包，再过扣子审核，再过渠道审核。失败先看页面提示和 [内容发布规范](https://docs.coze.cn/guides_content_principles)，不要反复点发布。

商店和调试区单次对话超时 **10 分钟**，超时表现为「运行中止」。工作流太长先拆短。

## 另一条路：全代码智能体

如果你更想「说一句话让平台把智能体写出来」，走 AI 编程，不是上面的低代码画布：

1. 打开 [code.coze.cn](https://code.coze.cn/) 首页。
2. 点 **智能体** 选项卡。
3. 写清功能、逻辑、约束，提交。
4. 等扣子 AI 建项目、跑测试、给出预览。

费用会走编程任务积分、内置集成、部署后的托管费。步骤详见 [开发智能体](https://docs.coze.cn/guides_vibe_coding_agent) 和 [Cookbook](./coze-cookbook.md#用-ai-编程生成全代码智能体)。

扣子（coze.cn）对话里的 AI 编程**不能**替代这一步去开发智能体和工作流。

## 常见陷阱

| 现象 | 原因 | 处理 |
|------|------|------|
| 智能体自称豆包 / DeepSeek | 人设没覆盖模型默认身份 | 在人设里写死名字和职责 |
| 加了插件却从不调用 | 人设里没有 `{` 引用 | 按官方要求引用工具 |
| 发布列表里没有豆包 | 2026-07-01 下线 | 改飞书 / 微信 / API |
| 调试区「运行中止」 | 商店/调试 10 分钟超时 | 缩短工作流 |
| 想私有化部署扣子编程 | 商业版不支持 | 用 [Coze Studio](https://github.com/coze-dev/coze-studio) |
| 进了豆包或 Trae | 进错产品 | 回到 [学习地图](./index.md) |
