# 千问术语表

不教操作。只保证「千问」两个字在本站口径一致。

## 概念关系

```
阿里 / 通义
├── 千问（助手产品，本目录）
│   ├── 网页 / App / 电脑端
│   ├── 办公助理 / 本地电脑 / 定时任务（产品内）
│   └── 千问输入法（同厂 App，不拆页）
├── 通义实验室（网关：千问 · 万相）
│   └── 万相（视觉生成）
├── 通义灵码 / Qoder CN（编码助手，#84）
├── 阿里云百炼（模型 API 平台，#85）
└── 国际站 Qwen
    ├── Qwen Studio（chat.qwen.ai）
    ├── Qwen Code（qwen.ai/qwencode）
    └── Research / 开源（qwenlm.github.io / QwenLM）
```

## 千问

**是什么：** 阿里的消费级 AI 助手。官方自称 **阿里官方AI助手**。入口 [qianwen.com](https://www.qianwen.com/)。

**为什么单独成页：** 它是面向个人的聊天与办事产品，和实验室网关、编码助手、模型 API 不是同一扇门。

**不是什么：** 不是通义实验室本身，不是通义灵码 / Qoder CN，不是百炼，不是 CLI。

## 通义 / 通义千问

**是什么：** 实验室与旧商店文案里的品牌词。通义实验室页头写「千问 · 万相」。应用宝仍有一段「通义介绍」。

**与千问的区别：** 现行消费助手页的产品名是 **千问**。不要把「通义」当成第二个助手，也不要把旧商店段落实成现行功能。

## 通义实验室

**是什么：** 模型与应用网关。[tongyi.aliyun.com](https://tongyi.aliyun.com/)。页脚「个人应用」指向千问。

**不是什么：** 不是 qianwen.com 的别名。

## 万相

**是什么：** 通义实验室并列的视觉生成大模型家族。入口 [landing?family=wan](https://tongyi.aliyun.com/landing?family=wan)。千问 App 的生视频文案点名 **Wan 2.7**。

**不是什么：** 不是千问里的一个 Tab 名称。本目录不写万相控制台教程。

## 通义灵码 / Qoder CN

**是什么：** 阿里云编码助手。官方仍保有 [lingma.aliyun.com](https://lingma.aliyun.com/)；产品页与帮助中心同时使用 **Qoder CN**（[qoder.com.cn](https://qoder.com.cn/)，帮助中心写 2026-05-20 由通义灵码更名）。本站 #84。

**与千问「代码」的区别：** 千问官方原文是对话里生成 / 检查小程序、网页、小游戏、SQL。Qoder CN 才是 IDE / CLI 编码产品。本目录只这一行。

## 阿里云百炼

**是什么：** 大模型服务与应用平台。[aliyun.com/product/bailian](https://www.aliyun.com/product/bailian)。本站 #85。

**与千问「API 服务」的区别：** 首页顶栏有 **API 服务** 按钮。调用模型、买 Token Plan 走百炼，不要在千问教程里教 `API Key`。

## Qwen Studio

**是什么：** 国际站助手。 [chat.qwen.ai](https://chat.qwen.ai/) 与 [qwen.ai](https://qwen.ai/) 的页面名就是 **Qwen Studio**。qwen.ai 原文：「an AI assistant for everyone, powered by the Qwen series models」。

**不是什么：** 不是「千问」二字的官方英译产品名，也不是 qianwen.com 的自动镜像。本目录不写安装。

## Qwen Code

**是什么：** 国际站终端编码 Agent。[qwen.ai/qwencode](https://qwen.ai/qwencode) 原文：open-source AI agent for the terminal。

**不是什么：** 不是千问首页的「代码」按钮。

## 办公助理 / 本地电脑

**是什么：** qianwen.com 首页上的模式。横幅写办公助理可解锁本地任务、手机远程操控、技能与连接器。

**不是什么：** 不是 QoderWork，也不是帮助中心「千问办公 (QwenWork)」那条产品线。后者属 #84 周边，本目录不写安装。

## 千问输入法

**是什么：** 首页横幅宣布的输入法 App。应用宝包名 `com.qianwen.ime`。

**不是什么：** 不是第二个聊天助手，不单独开手册。

## 交付形态（协议里的词）

用户服务协议把千问产品写成：网站 `qianwen.com`、网页、客户端（iOS、Android、Windows、Mac、HarmonyOS）、浏览器插件、小程序、H5，以及以后可能出现的载体。前几个有公开网页 / 商店入口；插件 / 小程序 / HarmonyOS 助手安装页 2026-08-19 没有找到，术语上承认名字，教程里不写步骤。

## 禁止写进正文的叫法

- 「千问 CLI」「Qwen IDE 插件」「千问国际版」——官方页没有这些产品名（国际站写的是 Qwen Studio）。
- 把百炼 Token Plan 或 Coding Plan 叫成「千问会员价」。
- 把商店用户评论里的额度、外卖减免、默认模型当成规格。
- 把淘宝 / 钉钉 / ECS 写成千问家族产品。
