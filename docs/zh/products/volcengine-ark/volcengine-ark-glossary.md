# 火山方舟术语表

只解释边界。操作回 [教程](./volcengine-ark.md)。

## 火山方舟

火山引擎的大模型服务平台：推理、评测、精调、API、模型广场。入口 [product/ark](https://www.volcengine.com/product/ark)，文档产品 ID 82379。

## 豆包 App

消费级聊天助手。[doubao.com](https://www.doubao.com/)。不是方舟控制台。见 #79。

## 豆包大模型

方舟文档侧栏里的模型家族（2026-08-19 可见「豆包大模型1.8」）。在程序里调它走方舟，不是打开豆包 App。

## Trae

同厂编程 IDE。方舟 CLI 可以接到 Trae。Trae 本身的安装见 #80。

## 扣子 / Coze

同厂 Agent 平台。产品页「模型能力扩展」提到扣子专业版。正文见 #81。

## 方舟 CLI

官方命令行。首页安装命令：`npm i @volcengine/ark-cli@latest -g`。产品页写它支持 Claude Code、Cursor、TRAE。

## Coding Plan

文档侧栏独立分组：套餐概览、快速开始、接入 AI 编程工具。不是 Agent Plan。

## Agent Plan

产品页活动文案：「方舟 Agent Plan 上线……限时 9.9 元起」。权益以产品页为准，不要和 Coding Plan 合成一张表。
