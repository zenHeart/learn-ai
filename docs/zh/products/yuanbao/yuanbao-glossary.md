# 元宝术语表

不教操作。只保证「元宝」两个字在本站口径一致。

## 概念关系

```
腾讯
├── 元宝（助手产品，本目录）
│   └── 元宝派（产品内公测玩法）
├── 混元（模型 / 研究品牌，#77）
│   ├── Hy3（首页写「已接入」的模型名）
│   └── Hy AI Studio（混元站页脚）
├── CodeBuddy（编程助手，#78）
├── WorkBuddy（办公工作台，页脚）
└── ima（知识管家，页脚）
```

## 元宝

**是什么：** 腾讯的消费级全能 AI 助手。官方英文名 Yuanbao。入口 [yuanbao.tencent.com](https://yuanbao.tencent.com/)。

**为什么单独成页：** 它是腾讯面向个人的聊天产品，和模型站、编程助手不是同一扇门。

**不是什么：** 不是混元本身，不是 CodeBuddy，不是 CLI。

## 混元 / Hy3

**是什么：** 腾讯的模型与研究品牌。站点 [hunyuan.tencent.com](https://hunyuan.tencent.com/)。首页说元宝「已接入最新的混元 Hy3 模型」。

**与元宝的区别：** 混元提供模型；元宝是其中一个消费产品。调用 API、下开源权重走混元站（#77），不要在元宝教程里教。

Play 商店简介仍出现「混元自研 T1 与 DeepSeek R1」。那是商店页原文，和首页 Hy3 文案并存。以客户端实际列表为准。

## 元宝派

**是什么：** App Store / Play / 软件中心写在元宝特色里的玩法。原文含「开启公测，支持在元宝派养龙虾」。

**不是什么：** 不是独立下载的第二个 App，也不是 WorkBuddy。

## CodeBuddy

**是什么：** 腾讯云代码助手。[codebuddy.cn](https://www.codebuddy.cn/)。本站 #78。

**与元宝「AI 编程」的区别：** 元宝官方原文是对话里「无需部署」跑 Python / C++。CodeBuddy 才是编码工具产品。本目录只这一行。

## WorkBuddy

**是什么：** 混元首页页脚产品之一。官网自称「腾讯出品的全场景 AI 办公工作台」（[workbuddy.cn](https://www.workbuddy.cn/)）。

**不是什么：** 不是元宝电脑版的别名。

## ima

**是什么：** 混元首页页脚产品之一。官网：「ima 是以知识库为基础的AI知识管家」（[ima.qq.com](https://ima.qq.com/)）。

**不是什么：** 不是元宝的「知识库模式」。

## Hy AI Studio

**是什么：** 混元 `/solutions` 页脚里的产品项，和元宝、WorkBuddy 并列。用于在混元站试模型，不是元宝的一个 Tab。

## 交付形态（协议里的词）

用户服务协议把服务范围写成：网页、PC 客户端、小程序、浏览器插件，以及以后可能出现的形态。前两个有公开下载/网页入口；后两个 2026-08-19 没有找到独立官方安装页，术语上承认名字，教程里不写步骤。

## 禁止写进正文的叫法

- 「元宝 CLI」「Yuanbao Code」「元宝 IDE 插件」——官方页没有这些产品名。
- 把 `hunyuan.tencent.com/bot/chat` 叫成「混元聊天」——canonical 指向元宝。
- 把商店用户评论里的额度、价格、默认模型当成规格。
