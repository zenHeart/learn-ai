# 元宝教程

> 先打开 [yuanbao.tencent.com](https://yuanbao.tencent.com/) 或 [下载中心](https://yuanbao.tencent.com/download)。本页只复述能在官方页核对的入口和能力。

## 目标与非目标

**写给谁：** 第一次用元宝的前端工程师。首页按钮文案是 **Log In**；具体登录方式以页面为准。

**你会完成：** 在网页或客户端里发出第一句；知道电脑版快捷键和官方能力边界。

**不会做：** 注册微信/QQ 教程、CodeBuddy 安装、编造模型切换步骤、列出未公布的 36 种后缀。

## 先决条件

- 能打开 `yuanbao.tencent.com`（部分网络会把该域名解析到 `198.18.0.0/15`，先换 DNS / 关 Fake-IP 再判断「打不开」）。
- 客户端系统要求以官方页为准，两处不要混成一个数：
  - 下载中心：macOS **11.3** 及以上，Windows **10** 及以上。
  - App Store：iOS / iPadOS **15.0** 或更高版本。

### 2. 发出第一句

首页未登录可见：「Hi, 我是元宝」「聊天、写作、搜索都在行，助你灵感无限」。登录后在输入框提问，或把文件拖进去（首页写了 **Drag the file here to upload**）。

页面底部有「内容由AI生成，仅供参考」。把它当产品声明，不当免责套话忽略。

### 3. 电脑版：划词和迷你窗

只在需要桌面唤起时装客户端。官方电脑版页（[evt/dl](https://yuanbao.tencent.com/evt/dl)）写明：

| 划词 | 「支持 AI 划词搜索、翻译，什么都能问元宝」 |

| 临时对话 | 「临时对话不会显示在历史对话记录中」 |
| 收藏 | 「精彩回答一键收藏」 |

软件中心电脑版还写了：全局划词（一键翻译、搜索、朗读，对话窗直显）；分组定制指令；直连腾讯文档导入与导出。

## 官方能力（按出处分组）

### 首页在说什么

[yuanbao.tencent.com](https://yuanbao.tencent.com/) description：

> 元宝是腾讯推出的全能 AI 助手，已接入最新的混元 Hy3 模型，拥有更强的文件处理交付能力，多种风格写作轻松驾驭、聊天陪伴更有人情味、AI 搜索更实用精准；智能识图、生图P图、拍题答疑等丰富能力，让您的工作学习生活更轻松高效。

可见导航还有 **Search**、**All Collections**、**Download Center**。Collections / Group 的规则官方没有单独文档，本页不编。

### 电脑版页在说什么

[evt/dl](https://yuanbao.tencent.com/evt/dl) 五个栏目：**混元 Hy3**、**AI 写作**、**AI 编程**、**AI 识图**、**AI 划词**。

和编程相关的原文只有两句：

- 「AI 编程无需部署，即时验证」
- 「支持Python、C++等多语言运行，无需部署即时验证」

这是**对话里跑代码**，不是克隆仓库、开 PR、接 MCP。仓库级编码去 [CodeBuddy](https://www.codebuddy.cn/)（本站 #78，这里不写教程）。

文件：「支持36种各式文件，代码、日志、技术文档都能读」。**没有**官方后缀表，不要补 PDF/DOCX 清单。

### 商店长描述还列了什么

App Store 与 Play「特色功能」在 2026-08-19 一致，包括：AI 图片编辑、拍题答疑、**元宝派（开启公测，支持在元宝派养龙虾）**、AI 录音笔（转写翻译不限时）、秒写报告 / 文案 / 代码、AI 讲解、AI 生成视频、语音通话、识图、拍照翻译、QQ 音乐、AI 绘图、生态联动微信 / 腾讯文档 / 腾讯新闻 / 微信读书、公众号与视频号信源、文档精读 36 种文件类型、秒搜热搜。

「生态联动微信」是商店里的一句能力，**不是**微信接入教程。

元宝派只当元宝内的公测玩法，不单独开页。

## 模型文案不要选边

三处官方说法同时存在（2026-08-19）：

| 出处 | 原文 |
|------|------|
| 首页 / 电脑版页 | 已接入 / 展示 **混元 Hy3** |
| App Store 版本说明 | 2.66–2.67「接入Hy3 preview」；2.76–2.78「Hy3模型正式上线」 |
| Play「关于此应用」 | 「腾讯混元自研T1与DeepSeek R1双推理模型……」 |

以你客户端里实际可选的名称为准。不要写「现在默认 DeepSeek」或「已经彻底下线 T1」。模型原理见 [Learn LLM](/zh/tech/fundamentals/LLM)。

## 常见陷阱

- **把元宝当成 Claude Code / Cursor。** 官方没有元宝 CLI，也没有官方 IDE 插件页。
- **按博客里的「双模四模型」写进笔记。** 那是旧文；当前首页写 Hy3，Play 简介仍提 T1 + R1。
- **补全 36 种格式。** 官方只给了数字和「代码、日志、技术文档」。
- **为小程序 / 插件写安装步骤。** 协议有名字，没有找到独立官方安装页。
- **把 `hunyuan.tencent.com/bot/chat` 当成混元聊天产品。** canonical 已指向元宝。
