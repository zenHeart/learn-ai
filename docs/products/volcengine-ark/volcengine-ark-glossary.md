# Volcengine Ark glossary

Boundaries only. How-to stays on the [tutorial](./volcengine-ark.md).

## Volcengine Ark

Volcengine large-model platform: inference, eval, fine-tune, API, model square. Door: [product/ark](https://www.volcengine.com/product/ark). Docs product id 82379.

## Doubao app

Consumer chat assistant at [doubao.com](https://www.doubao.com/). Not the Ark console. See #79.

## Doubao models

The model family in the Ark docs sidebar (Doubao 1.8 visible on 2026-08-19). Call them through Ark, not the chat app.

## Trae

Same-vendor coding IDE. Ark CLI can connect to it. Trae install is #80.

## Coze

Same-vendor agent platform. The product page names Coze Pro under capability expansion. Body: #81.

## Ark CLI

Official CLI. Homepage install: `npm i @volcengine/ark-cli@latest -g`. Product page: supports Claude Code, Cursor, TRAE.

## Coding Plan

A docs-sidebar group: overview, quick start, coding-tool connect. Not Agent Plan.

## Agent Plan

Product-page offer: “from 9.9 CNY” for a limited time. Do not merge it with Coding Plan.
