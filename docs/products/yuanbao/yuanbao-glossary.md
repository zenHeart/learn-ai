# Yuanbao glossary

No how-to. This page only keeps the word “Yuanbao” consistent on this site.

## Concept map

```
Tencent
├── Yuanbao (assistant product, this directory)
│   └── Yuanbao Pai (in-app public beta)
├── Hunyuan (model / research brand, #77)
│   ├── Hy3 (the model name on today's home page)
│   └── Hy AI Studio (Hunyuan footer)
├── CodeBuddy (coding assistant, #78)
├── WorkBuddy (office workbench, footer)
└── ima (knowledge steward, footer)
```

## Yuanbao

**What it is:** Tencent's consumer all-in-one AI assistant. English name Yuanbao. Door: [yuanbao.tencent.com](https://yuanbao.tencent.com/).

**Why it has a page:** it is the personal chat product. It is not the model site and not the coding assistant.

**What it is not:** Hunyuan itself, CodeBuddy, or a CLI.

## Hunyuan / Hy3

**What it is:** Tencent's model and research brand. Site: [hunyuan.tencent.com](https://hunyuan.tencent.com/). Home says Yuanbao is connected to the latest Hunyuan Hy3 model.

**Versus Yuanbao:** Hunyuan ships models; Yuanbao is one consumer surface. APIs and open weights belong on the Hunyuan handbook (#77).

Play's about-text still mentions Hunyuan T1 and DeepSeek R1. That store sentence coexists with home's Hy3 copy. Trust the list in the client.

## Yuanbao Pai

**What it is:** a Yuanbao feature in App Store / Play / Software Center copy, including a public beta that mentions raising lobsters.

**What it is not:** a second downloadable app, and not WorkBuddy.

## CodeBuddy

**What it is:** Tencent Cloud coding assistant. [codebuddy.cn](https://www.codebuddy.cn/). Site issue #78.

**Versus Yuanbao “AI coding”:** Yuanbao's official wording is running Python / C++ in the thread with no deploy. CodeBuddy is the coding-tool product. This directory stops at this row.

## WorkBuddy

**What it is:** a Hunyuan home-footer product. The site calls it Tencent's all-scenario AI office workbench ([workbuddy.cn](https://www.workbuddy.cn/)).

**What it is not:** a nickname for Yuanbao desktop.

## ima

**What it is:** a Hunyuan home-footer product. Official line: an AI knowledge steward built on a knowledge base ([ima.qq.com](https://ima.qq.com/)).

**What it is not:** a “knowledge-base mode” inside Yuanbao.

## Hy AI Studio

**What it is:** a footer item on Hunyuan `/solutions`, listed with Yuanbao and WorkBuddy. It is a model playground on the Hunyuan site, not a Yuanbao tab.

## Delivery shapes (words from the agreement)

The user agreement lists web, PC client, mini program, browser plugin, and future shapes. The first two have public doors. The last two had no standalone official install page on 2026-08-19 — keep the names, do not write install steps.

## Do not write these as product names

- “Yuanbao CLI”, “Yuanbao Code”, “Yuanbao IDE plugin” — no official page uses them.
- Calling `hunyuan.tencent.com/bot/chat` “Hunyuan chat” — it canonicalizes to Yuanbao.
- Treating store-review quotas, prices, or default models as specs.
