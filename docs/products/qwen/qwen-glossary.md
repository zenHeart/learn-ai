# Qwen glossary

No how-to. This page only keeps the word “Qwen” consistent on this site.

## Concept map

```
Alibaba / Tongyi
├── Qwen (assistant product, this directory)
│   ├── Web / App / desktop
│   ├── Office assistant / local PC / scheduled tasks (in-product)
│   └── Qwen IME (same-vendor app, no handbook)
├── Tongyi Lab (gateway: Qwen · Wan)
│   └── Wan (visual generation)
├── Tongyi Lingma / Qoder CN (coding assistant, #84)
├── Alibaba Cloud Bailian (model API platform, #85)
└── International Qwen
    ├── Qwen Studio (chat.qwen.ai)
    ├── Qwen Code (qwen.ai/qwencode)
    └── Research / open source (qwenlm.github.io / QwenLM)
```

## Qwen / 千问

**What it is:** Alibaba’s consumer AI assistant. Official line: **阿里官方AI助手**. Door: [qianwen.com](https://www.qianwen.com/).

**Why it has a page:** it is the personal chat-and-get-things-done product. It is not the lab gateway, the coding assistant, or the model API.

**What it is not:** Tongyi Lab itself, Tongyi Lingma / Qoder CN, Bailian, or a CLI.

## Tongyi / 通义千问

**What it is:** a brand word on the lab site and in older store copy. Tongyi Lab’s header says “千问 · 万相”. Yingyongbao still has a “通义介绍” block.

**Versus Qwen:** the live consumer page’s product name is **千问**. Do not treat “Tongyi” as a second assistant, and do not promote stale store paragraphs into current features.

## Tongyi Lab

**What it is:** a model and app gateway. [tongyi.aliyun.com](https://tongyi.aliyun.com/). Footer “个人应用” points at Qwen.

**What it is not:** a nickname for qianwen.com.

## Wan

**What it is:** Tongyi Lab’s visual-generation model family. Door: [landing?family=wan](https://tongyi.aliyun.com/landing?family=wan). Qwen App video copy names **Wan 2.7**.

**What it is not:** a tab name inside Qwen. This directory does not document a Wan console.

## Tongyi Lingma / Qoder CN

**What it is:** Alibaba Cloud’s coding assistant. [lingma.aliyun.com](https://lingma.aliyun.com/) still exists; product pages and help also say **Qoder CN** ([qoder.com.cn](https://qoder.com.cn/); help says the Lingma rename landed 2026-05-20). Site issue #84.

**Versus Qwen “code”:** Qwen’s official wording is generating / checking mini programs, pages, mini games, and SQL in the thread. Qoder CN is the IDE / CLI product. This directory stops at this row.

## Alibaba Cloud Bailian

**What it is:** the model-service and app platform. [aliyun.com/product/bailian](https://www.aliyun.com/product/bailian). Site issue #85.

**Versus Qwen “API 服务”:** home has an **API 服务** button. Calling models and buying a Token Plan belong on Bailian. Do not teach `API Key` in the Qwen tutorial.

## Qwen Studio

**What it is:** the international assistant. [chat.qwen.ai](https://chat.qwen.ai/) and [qwen.ai](https://qwen.ai/) name the product **Qwen Studio**. qwen.ai copy: “an AI assistant for everyone, powered by the Qwen series models”.

**What it is not:** the official English product name for 千问, and not an automatic mirror of qianwen.com. This directory does not write the install.

## Qwen Code

**What it is:** the international terminal coding agent. [qwen.ai/qwencode](https://qwen.ai/qwencode) calls it an open-source AI agent for the terminal.

**What it is not:** the **代码** chip on the Qwen home page.

## Office assistant / local PC

**What they are:** modes on qianwen.com. The banner says the office assistant unlocks local tasks, phone remote control, skills, and connectors.

**What they are not:** QoderWork, and not the help-center product “千问办公 (QwenWork)”. That line sits next to #84. This directory does not write the install.

## Qwen IME

**What it is:** the input-method app announced on the home banner. Yingyongbao package `com.qianwen.ime`.

**What it is not:** a second chat assistant. No separate handbook.

## Delivery shapes (words from the agreement)

The user agreement lists website `qianwen.com`, web, clients (iOS, Android, Windows, Mac, HarmonyOS), browser plugin, mini program, H5, and future carriers. The first group has public web / store doors. Plugin / mini program / HarmonyOS assistant install pages were not found on 2026-08-19 — keep the names, do not write install steps.

## Do not write these as product names

- “Qwen CLI”, “Qwen IDE plugin”, “Qwen international edition” — no official page uses them (the international site says Qwen Studio).
- Calling a Bailian Token Plan or Coding Plan “Qwen membership pricing”.
- Treating store-review quotas, takeout discounts, or default models as specs.
- Listing Taobao / DingTalk / ECS as Qwen family products.
