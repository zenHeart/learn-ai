# OpenClaw learning map

> **OpenClaw** is a multi-channel AI-agent gateway on any OS. Official [Getting started](https://docs.openclaw.ai/start/getting-started): install, onboard, and chat in about five minutes. You end with a running Gateway, configured auth, and a working session.
>
> Product: [openclaw.ai](https://openclaw.ai/). Not the Pi CLI. Not a Feishu / WeChat product tutorial.
