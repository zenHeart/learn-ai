# OpenClaw glossary

**OpenClaw** — Self-hosted multi-channel gateway. **Gateway** listens on 18789. **Dashboard** is `openclaw dashboard`. **Pi** is the terminal harness ([Pi](/products/pi-agent/)). **Channels** are adapters, not IM product handbooks.
